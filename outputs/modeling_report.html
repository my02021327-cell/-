Part 1

원자료와 구조 파악

연도별 엑셀 6개(2018–2023), 각 파일에 Data 시트가 있고 3단 병합 헤더 구조. 소화조 A/B 2계열이 각각 투입량·온도(상/중/하)·pH·CODcr·TS·VS·VFA·알칼리도·개별VFA·메탄함량· 바이오가스발생량을 가진다.

1.1 첫 번째 함정 — 연도별 컬럼 레이아웃 불일치

고정 컬럼 인덱스로 읽으면 2018–2020 과 2021–2023 이 서로 다른 항목을 가리킨다. 예: 컬럼 23이 2018–2020 에서는 NH3-N, 2021–2023 에서는 투입량. → 전 구간을 헤더 이름 기반으로 파싱하도록 전환.

1.2 설계 제원 확보

Data 계산 시트에서 소화조 용량을 찾았다. 이 값이 뒤(Part 8)에서 지연 모델의 결정적 근거가 된다.

유효용적 V = 4,000 (A조) + 4,000 (B조) = 8,000 ㎥ 평균투입 Q = 197.1 ㎥/일 (설계 209.05 ㎥/일) → HRT = V/Q = 40.6 일, 희석률 D = 1/HRT = 0.0246 /일 → 1일 투입 = 조 용적의 2.46 %

Part 2

타깃 정의와 누수 차단

타깃은 일별 메탄생성량(Nm³/d). 여기서 두 종류의 누수를 사전 차단했다.

  1. 결정론적 누수 — 메탄생성량 = 바이오가스 × 메탄함량 ÷ 100 이 오차 0으로 성립한다. 따라서 바이오가스·메탄함량을 독립변수에서 완전 제외.
  2. 미래 정보 누수 — 학습 2018–2022 / 홀드아웃 2023 시간분할. lag·이동평균 등 파생은 연속 일별 캘린더에서 먼저 계산한 뒤 결측일을 삭제한다(순서를 바꾸면 shift 가 달력상 지연을 왜곡).
수율(비메탄수율)을 예측 대상에서 제외한 이유

수율 = 메탄 ÷ 금일 투입 VS. 분모가 금일 값이라 어제까지의 데이터로 오늘 수율을 예측하는 것은 순환적이다. 뒤(Part 12)에서 이 분모 효과가 경보 검증까지 오염시키는 것을 실제로 확인하게 된다.

Part 3

전처리 원칙

  • 결측일 삭제 — 타깃·사용 피처에 결측이 있는 날은 보간 없이 제거(dropna).
  • 예외적 보간 — 농도처럼 완만히 변하는 값을 입력 이력 구성에 쓸 때만 시간보간을 허용하고 문서에 명시(예: 유입 VS%). 모델 학습행에는 적용하지 않는다.
  • 물리적 불가능값 제거 — CH4 함량 40 % 미만/75 % 초과는 계측 오류로 간주해 제거 (원자료에 350.3 % 같은 값 존재).
  • 표준화 불필요 — 최종 모델이 트리·상태공간 기반이라 스케일링 없이 학습.
Part 4

1차 모델링 — XGBoost, 2상 집중

과제 요구(2상 집중 / lag 임의선정 후 가중치 최대일 선택 / 피처 10–15개 / 결측일 삭제)를 그대로 구현했다.

4.1 lag 선택 — XGBoost gain 방식

투입량합계의 lag0 … lag15 를 모두 넣어 학습한 뒤 gain 중요도 최댓값 날을 선택 → 2일(gain 점유율 23 %). 이 선택은 Part 8 에서 기각된다.

4.2 Model-1 : 2상 소프트센서 (12 피처)

소화조 pH·온도·VS·CODcr·TS·VFA·알칼리도·VFA/ALK + 투입량합계·VS_in·반입량 + 선택 lag.

Part 5

persistence 라는 벽

여기서 프로젝트의 성격을 규정하는 사실이 드러났다.

메탄 일별 자기상관 (lag 1) = 0.917 연평균 추이 2018: 7,164 → 2019: 7,346 → 2020: 6,940 2021: 6,568 → 2022: 6,430 → 2023: 6,374 Nm³/일

매우 매끄러운 시계열이라 persistence(어제값)만으로 2023 R² ≈ 0.88 이 나온다. 동시에 연 단위 하향 국면이동이 있어, 학습기 관계를 외삽하는 트리 계열은 수준(level)을 잃는다.

정정 1 — persistence 정책

초기에는 persistence 를 피처로 앵커링해 baseline 을 넘겼다(R² 0.877→0.883). 그러나 "persistence 로 예측하지 말라"는 요구에 따라 persist 피처를 전 모델·메타입력에서 제거하고, persistence 는 비교 기준으로만 사용하도록 전면 재설계했다.

그 결과 운전변수 전용 트리는 R² ≈ 0.60 으로 기준선에 크게 미달한다. 이것을 감추지 않고 기록한다 — 과거 메탄 없이 강한 자기상관 기준선을 트리로 이기는 것은 어렵다.

그렇다면 persist 피처 없이 무엇이 기준선을 넘는가? → 시계열 모델(Part 6).

Part 6

앙상블 확장 — RandomForest, 그리고 시계열

6.1 RandomForest 추가와 스태킹

Base 를 RF + XGB 로 늘리고 비음수 Ridge 메타로 스태킹. 메타피처는 학습기간 TimeSeriesSplit(5) 확장창 OOF 로 만들어 누수를 차단했다. 그러나 두 모델은 같은 트리 계열이라 잔차 상관 ≈ 0.99 — 결합 이득이 거의 없다.

6.2 시계열 base 투입 — 다양성의 실질

SARIMAX(1,0,1) + 외생 투입부하는 선형 상태공간(칼만필터) 모델로 트리와 계열이 달라 잔차 상관 ≈ 0.93. 결측 많은 일별 메탄을 칼만필터가 자연 처리하고 자기상관 구조를 직접 모형화한다.

Part 8 · 핵심

지연(lag) 3라운드 — 두 번의 정정

투입이 언제 메탄으로 나타나는가. 이 질문에 세 번의 서로 다른 답이 나왔고, 두 번 정정했다.

Round 1 — XGBoost gain : 2일

트리 분할 이득 기준. 문제: ① 서로 강하게 상관된 lag 후보 중 하나가 임의로 뽑히고 ② 두 계열의 자기상관이 만드는 허위 상관을 통제하지 못한다.

Round 2 — 프리화이트닝 교차상관 : 0일

Box-Jenkins 절차(원인계열의 AR 필터를 x·y 양쪽에 적용) + 순열검정 + 이동블록 부트스트랩.

먼저 해결해야 했던 제약

메탄이 평일만 측정되어 달력일 연속 관측 최대 6일 → AR(7) 프리화이트닝이 수학적으로 불가능(유효표본 0). 영업일(월–금) 격자를 자연 표본격자로 삼아 해결 (결측 19.6 %, 연속런 최대 59). 참고로 제공된 로그의 'AR(7) prewhitening' 은 달력일 원자료에서는 그대로 성립하지 않는다.

Round 3 — 반응공학 : 분포지연

정정 2 — 'lag 0' 은 생물학적으로 성립하지 않는다

① 반응 메커니즘 가수분해→산생성→아세트산생성→메탄생성의 다단계 반응이며 입자성 유기물의 가수분해가 율속단계다. 투입 VS 가 당일 메탄이 되는 것은 불가능하다.

② 물질수지(결정적) HRT 40.6일, 1일 투입 = 조 용적의 2.46 %. 하루치 투입이 당일 메탄 발생을 지배한다는 것은 물질수지상 성립할 수 없다.

③ 추정기 오용 투입량 자기상관이 lag1 0.94·lag30 0.63 으로 극단적이라 feed(t)와 feed(t−20)이 사실상 구분되지 않는다. 단일 peak 교차상관은 공선성 평지에서 임의의 한 점을 고르는 것이며, 분포지연 과정에 잘못 적용된 추정기다. lag0 신호의 실체는 급이 시 액상치환(수리·측정 효과) + 음폐수(유입 59 %)의 가용성 COD 급속전환이지, 기질의 생물학적 전환지연이 아니다.

올바른 모델 — CSTR 1차반응 2-pool 분포지연

완전혼합조 물질수지 : dS/dt = D·S_in − (k_h + D)·S → 임펄스 응답은 시간상수 τ = 1/(k_h + D) 의 지수감쇠 기질 이질성 (가용성 음폐수 59 % / 입자성 가축분뇨·음식물 41 %) → 2-pool S_j(t) = Σ (1/τ_j)·e^(−τ/τ_j)·feed(t−τ) ← 1차반응의 정확한 이산해 = EWMA 메탄(t) ~ b_fast·S_fast(t) + b_slow·S_slow(t) + (소화조 자체 동특성)

τ 는 롤링-오리진 CV 로 선택(홀드아웃 미사용)하고, 선택된 τ_slow 에서 가수분해 상수를 k_h = 1/τ_slow − D 로 역산해 문헌값과 대조했다.

CV 가 독립적으로 고른 τ_fast = 1일 / τ_slow = 8일은 가수분해 상수 k_h = 0.100 /일을 함의한다. 이는 음식물류·가축분뇨 중온소화의 문헌값(0.05–0.2/일)과 정확히 일치한다. 데이터와 생물학이 독립적으로 수렴한 강한 검증이다.

적합 기여도 fast 50.9 % : slow 49.1 % — 응답의 절반이 지연된 slow pool. 결합 임펄스응답의 평균지연 3.31일, t50 1일, t90 10일. 즉 정답은 '0일'이 아니라 수일에 걸친 분포지연이다.

생물학 반영의 대가는 사실상 0 — 임시 피처(lag0+load10) 대비 CV 0.8834→0.8819, 홀드아웃 0.9054→0.9024 로 차이가 폴드 표준편차(±0.027) 내다. 정확도를 잃지 않고 역학적 타당성·해석가능성을 얻었다. 성능이 동률일 때는 기계적 산출물보다 메커니즘에 부합하는 표현을 택하는 것이 옳다.

Part 8-B · 문헌 대조

"30일 뒤에 메탄이 나온다"는 통설의 재검토 — 2상 공정 반영

2상 구조가 τ 를 짧게 만드는 이유 — 모델 결과의 역학적 근거

메탄생성조는 이미 산발효를 마친 기질을 받는다(유기산화조 pH 5.5, COD 131,528 mg/L). 단상 소화조에서 율속단계인 가수분해가 앞단에서 이미 수행되었으므로, 메탄생성조가 담당하는 아세트산생성·메탄생성은 상대적으로 빠른 반응이다.

이것이 본 모델의 2-pool 에서 fast pool(τ=1일)이 50.9 % 를 차지하는 이유다. 단상 소화조라면 fast 비중이 이렇게 클 수 없다. 2상 공정 구조가 모델 결과를 독립적으로 설명한다.

용어 정정 — k 를 '가수분해 상수'로 부른 것은 부정확

Part 8 에서 τ_slow 로부터 역산한 k = 1/τ_slow − D = 0.100 /일 을 '가수분해 상수 kh' 라고 표기했다. 2상 공정에서는 가수분해가 앞단에서 끝나므로, 이 값은 순수 가수분해 상수가 아니라 메탄생성조 내 유효 전환속도 상수 로 부르는 것이 정확하다.

따라서 문헌 BMP 가수분해 상수(0.19–0.65/일, 단상 회분식 최적조건)와 직접 비교하는 것도 엄밀하지 않다. 본 시설 값이 더 낮은 것은 ① 회분식이 아닌 연속 완전혼합조이고 ② 만성 암모니아 저해(FAN 중앙 389 mg/L)로 실제 전환속도가 억제되기 때문으로 본다. Part 8 의 '문헌값과 정확히 일치' 라는 서술은 이 범위 안에 든다 정도로 완화한다.

8B.5 결론

  • "30일 뒤 메탄"은 오독 — 30일은 완전 분해를 보장하는 설계 체류시간이지 투입–메탄 지연시간이 아니다. BMP 곡선은 초기 3–5일에 집중된다.
  • 본 시설 메탄생성조 HRT = 40.4일(설계 38.3일) — 문헌 메탄생성조 권장(12–25일)보다 길다. 저부하 여유 운전 중이라는 앞선 관찰과 일치한다.
  • 산생성조 HRT ≈ 1–3일 추정 — pH 5.51 이 근거이나 용적 자료가 없어 확정 불가.
  • 투입→메탄 응답 시간상수 τ ≈ 8일(t90 18.5일). 2상 구조로 가수분해가 선행되어 단상 대비 빠른 것이 타당하다.
  • 모델의 2-pool(fast 1일 51 % + slow 8일 49 %)은 2상 공정 구조와 정합한다.

12.4 검증 관점 — 정직한 한계

이 경보를 '성능저하 예측력'으로 검증하는 것은 이 데이터로는 불가능하다.

  • CH4 % 는 부하와 교란 — r(OLR, CH4 %) = −0.118, 저부하일수록 상승
  • 비메탄수율은 분모 교란
  • 안정성 경보의 점검·위험 표본이 n=28·13 으로 과소
  • 무엇보다 과거 데이터에는 운전자 개입이 이미 반영되어 있다. 이탈이 생기면 운전자가 조치했으므로 '경보 후 악화'가 관측되지 않는 것이 정상이다

→ 본 시스템은 성능 예측기가 아니라 상태 감시기(condition monitor) 이며, 타당성은 ⓐ 설정값의 공정공학적 근거 ⓑ 합리적 발화율 ⓒ off-normal 상태 포착으로 판단한다.

Part 14

한계와 다음 단계

정직하게 남기는 한계

  • 앙상블의 실질 — 메타 가중치가 SARIMAX ≈ 1.0 / 트리 = 0 으로, 스태킹은 사실상 단일 시계열 모델로 수렴한다. 다양성 base 를 여러 종 시험했으나 모두 악화했다.
  • 경보의 검증 불가 — 위 12.4 참조. 성능 예측력으로는 검증할 수 없다.
  • FAN 감시의 간헐성 — NH4-N 가용률이 10.5 %뿐이라 핵심 위험 지표가 드문드문 측정된다.
  • 잔차 백색 — 모델 개선 여지가 사실상 소진되었다.

다음 단계 (우선순위 순)

  1. NH4-N 정기 계측 확대 — FAN 이 이 시설의 핵심 위험인데 감시가 간헐적이다.
  2. 개별 VFA 계측 개시 — 프로피온산/아세트산 비(>1.4)는 검증된 조기경보인데 데이터가 없다.
  3. 온라인 VFA·가스조성 실시간 계측 — 화학상태를 '동시대'가 아닌 '선행' 정보로 전환하면 소프트센서가 기준선을 넘어설 여지가 생긴다.
  4. 조별 #A/#B 분리 모델링 — 표본이 2배가 되고 조별 국면차를 반영할 수 있다.
  5. 암모니아 저감 운전 — 투입 260 ㎥/일까지 OLR 1.52 로 여유가 크다. 증산 여력이 있으나 실제 제약은 OLR 이 아니라 암모니아 축적일 가능성이 높아 가축분뇨 비율 조정이 동반돼야 한다.
