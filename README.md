# BioGuard-AI — 혐기성 소화조 메탄 예측 앙상블 모델

영천 통합바이오가스화시설의 6년간(2018.01~2023.12) 일별 운전 데이터를 학습하여
**메탄발생량(methane)** 과 **메탄발생비=수율(MY)** 를 동시에 추정하는 멀티아웃풋
앙상블 모델이다. 이질적 Base Model 을 **NNLS(비음수 최소자승) 스태킹** 메타러너로
결합하여, 2023년 홀드아웃(미래) 구간에서 개별 모델을 능가하는 일반화 성능을 확보한다.

> 「바이오가스법」(2023.12 시행) 이행 지원을 위한 데이터 기반 운전 의사결정 지원
> 시스템의 예측 엔진에 해당한다.

## 데이터

| 파일 | 내용 |
|------|------|
| `data/master.xlsx` | 운전 변수(반입량·투입량·유입/소화조 pH·TS·VS·VFA·알칼리도·온도·OLR 등) |
| `data/targets.xlsx` | `methane`(메탄발생량), `VS_in`(투입 VS부하), `MY`(수율=`methane`/`VS_in`) |

- 총 2,190행(365일 × 6년) 중 두 종속변수가 모두 존재하는 **1,213 set** 사용
- 학습 2018~2022 (1,061 set) / **홀드아웃 2023 (152 set)** — 미래 정보 누수 차단

### 결정론적 관계 · 누수 처리
- `MY = methane / VS_in` 이 오차 ~1e-15 로 성립함을 확인.
  `VS_in`(투입 부하)은 예측 시점에 알 수 있는 **입력 변수**로 유지하고,
  종속변수인 `methane` 은 피처에서 제외하여 누수를 차단한다.
- 결측 과다 열(`유입_TN` 85%, `소화조_TN` 83%, `소화조_NH4N` 90%)은 제거.
  나머지 소량 결측은 시간순 선형 보간.

## 파이프라인 (`src/`)

| 모듈 | 역할 |
|------|------|
| `data.py` | 로딩·병합·전처리 + 시계열 Feature Engineering |
| `ensemble.py` | Base Model 정의 + `NNLSStackingEnsemble` (비음수 스태킹) |
| `train.py` | 학습·평가 파이프라인(엔드투엔드) |
| `signal.py` | 신호등 관제 등급 분류 + 예측 시각화 |

### Feature Engineering
핵심 운전변수에 대해 **rolling window(7·14·30일)** 평균·표준편차와
**자기회귀 lag(1·7·14일)** 피처, 산성화 지표(VFA/알칼리도 비)·VS 부하비 파생변수를
생성한다(총 101개 피처).

### 앙상블 구조
- **Base Model** : RandomForest · MLP(신경망) · HistGradientBoosting · ExtraTrees
  - 보고서의 base 구성은 RF·MLP·LSTM·Transformer 이나, 본 실행 환경은 딥러닝
    프레임워크(torch/tensorflow) 설치가 프록시 정책으로 차단되어 있어
    LSTM/Transformer 는 시계열 피처를 입력받는 이질적 sklearn 학습기
    (HistGBM·ExtraTrees)로 대체하였다. **NNLS 비음수 스태킹 방법론은 동일**하다.
- **Meta Model** : 종속변수별 **NNLS 비음수 가중 선형결합**
  - 단순 K-fold OOF 로 가중치를 학습하면 학습기간 내부 순위가 2023 국면이동
    홀드아웃과 달라 특정 base 를 과대가중한다. 이를 막기 위해 학습기간의
    **가장 최근 연도(2022)를 메타 검증 블록**으로 분리(그 이전 데이터로 base 학습)
    하여 미래 일반화에 맞춘 비음수 가중치를 학습한 뒤, base 를 전체 학습데이터로
    재학습하여 홀드아웃을 예측한다.

## 실행

```bash
pip install -r requirements.txt
python -m src.train      # 학습·평가·시각화 (outputs/ 생성)
python -m src.signal     # 신호등 요약·그래프 재생성(선택)
```

## 결과 (2023 홀드아웃)

| 모델 | 메탄발생량 R² | RMSE | 수율(MY) R² | RMSE |
|------|:---:|:---:|:---:|:---:|
| RandomForest | 0.532 | 751.2 | 0.342 | 0.166 |
| MLP | -1.327 | 1674.5 | -1.650 | 0.333 |
| HistGBM | -0.037 | 1117.9 | 0.450 | 0.152 |
| ExtraTrees | 0.693 | 607.8 | 0.526 | 0.141 |
| **Ensemble (NNLS)** | **0.706** | **595.0** | **0.718** | **0.109** |

- **앙상블이 두 종속변수 모두에서 모든 단일 모델을 능가**한다
  (수율은 최고 단일모델 대비 R² +0.19).
- MLP 는 2023 국면이동에서 일반화에 실패(R²<0)하며, NNLS 가 이를 **0 가중치**로
  정확히 배제한다 — 보고서의 관찰(“MLP 일반화 실패, 단순·제약 결합이 유리”)과 일치.
- **신호등 등급(정상/주의/점검/위험) 예측 정확도 72.4%.**

### 산출물 (`outputs/`)
- `metrics.json` — 모델별 R²/RMSE/MAE, NNLS 가중치, 신호등 정확도
- `predictions_2023.csv` — 2023 실측 vs 앙상블 예측
- `predictions_2023.png` — 시계열 비교 + 신호등 밴드 그래프

## 신호등 관제 기준 (수율)
| 등급 | 조건 | 의미 |
|------|------|------|
| 🟢 정상 | MY ≥ 0.70 | 양호 |
| 🟡 주의 | 0.60 ≤ MY < 0.70 | 모니터링 강화 |
| 🟠 점검 | 0.50 ≤ MY < 0.60 | 공정 점검 |
| 🔴 위험 | MY < 0.50 | 산성화 등 이상 대응 |
