# BioGuard-AI — 영천 BGP 메탄 예측 · 운전권고 · SCADA 관제

영천 통합바이오가스화시설의 일별 운전자료(2018-01-01 ~ 2023-09-17, 2,086일)로
**지평 구간별 메탄 발생량 예측 모델**을 만들고, 예측된 변화에 대해 **운전 변수 제어를
근거와 함께 권고**하며, 산업용 HMI 콘솔에 실시간으로 서빙한다.

```
데이터 → 품질규칙 → 결측보간(가림실험 선택) → 4각도 피처 → 지평 구간별 모델
      → rolling-origin 검증 → 채택 → 반사실 기반 운전권고 → FastAPI → HMI
```

## 빠른 시작

```bash
pip install -r requirements.txt

python -m src.bgp.train_bands      # 1) 구간별 모델 평가·채택   → outputs/bands/
python -m src.bgp.serve_models     # 2) 채택 모델 전체 재적합   → outputs/models/
python -m server.app               # 3) http://127.0.0.1:8000

python scripts/smoke_test.py       # 파이프라인·API 연기 시험
```

주요 옵션 — `--fast`(후보 축소) · `--with-gru`(시계열 심층학습 포함) · `--ablation`(각도별 단독 성능)

## 자료 — 설계를 결정한 한 가지 사실

```
CH4_m3d = biogas_AB_m3d × CH4_pct / 100

biogas_AB_m3d   결측  0.0 %     ← 유량계는 매일 기록된다
CH4_pct         결측 39.4 %     ← 가스분석을 매일 하지 않는다
```

타깃 결측 821일은 **전부 농도 미측정일**이다. 그래서 유량은 완전 관측 계열로 시계열
모델에 그대로 쓰고, **농도만** 보간한다. `data/master_bgp_2018_2023.csv` (2,086일 × 61열)가
정본이며, A/B 계열을 평균 낸 옛 `data/master.xlsx` 는 쓰지 않는다.

## 네 각도로 예측한다

| 각도 | 내용 | 결측률 |
|---|---|:---:|
| **A. 기질 성상** | 반입 3기질 조성·투입량, 산발효조 TS/VS/pH/COD, 여액 성상 | 21.3 % |
| **B. 내부 이화학** | pH, VFA, ALK, VFA/ALK, TS/VS, COD, 온도, NH₃-N, FAN | 47.6 % |
| **C. VS 물질수지** | 유입/유출/소비 VS, 분해율, 조내 VS, OLR, HRT, Y_COD | 34.4 % |
| **D. 시계열 구조** | 유량·농도·타깃의 시차/이동통계/추세, 관측 신선도, 달력 | 26.2 % |

인과적 변환(현재값·이동평균 3/7/14/30일·시차 1/3/7/14일·추세)으로 **536개 피처**.
각 각도는 단독으로도 평가한다 — 어느 각도가 실제로 정보를 주는지가 성능만큼 중요하다.

## 결측 보간 — 논문 근거로 하되, 논문대로만 하지 않는다

Meola & Weinrich (2025) Algorithm 1 의 소프트센서(BayesianRidge → AdaBoost → GBR)를
구현했다. 그리고 **가림 실험으로 실제로 재봤다**.

| 방식 | CH₄ 농도 복원 MAE | 판정 |
|---|---:|---|
| 소프트센서 (논문) | 1.510 %p | ❌ 가장 나쁘다 |
| 소프트센서 + 시간이웃 | 0.640 %p | |
| 전방보간 (ffill) | 0.768 %p | 실시간 경로 채택 |
| **선형보간** | **0.536 %p** | ✅ 배치 재구성 채택 |

농도는 ACF(1)=0.968 로 매우 매끄러운데 동시점 설명변수는 약하다. 논문 방식을 그대로 쓰면
보간 오차가 약 3배가 된다. 그래서 논문의 **취지**(NaN 처리는 최적화 대상이다)를 따라
방식 선택 자체를 폴드 안에서 가림 실험으로 한다.

> 보간 라벨은 **학습에만** 쓴다(1,265 → 2,086일). 평가는 **실측 라벨에서만** 한다.

## 지평 구간별 모델

persistence 성능이 지평에 따라 완전히 갈리므로 하나의 모델로 두 체제를 맞출 이유가 없다.

| 지평 | 1일 | 3일 | 7일 | 14일 | 30일 | 60일 | 90일 |
|---|---:|---:|---:|---:|---:|---:|---:|
| persistence R² | 0.934 | 0.787 | 0.514 | 0.234 | −0.612 | −1.820 | −2.624 |

**1–3 / 3–5 / 5–7 / 7–14 / 14–30 / 30–60 / 60–90일** 일곱 구간을 각각 독립으로
적합·선택·평가한다. 구간 안에서는 지평 h 를 피처로 넣는 **직접 다단계**이고,
표적은 **수준(level)** 과 **원점 대비 잔차(delta)** 두 형태를 폴드 안에서 고른다
(delta ≡ 0 이 정확히 naive 이므로 하한이 보장된다).

라인업 — HistGBM · RandomForest · ExtraTrees · ElasticNet · BayesianRidge · kNN ·
**FlowConc**(유량×농도 분해) · **GRU** · SARIMAX · NNLS 스태킹, 그리고 기준선 naive·SeasonalNaive.

## 결과 — 구간별 폴드밖 성적

| 지평 구간 | 채택 모델 | **pooled R²** | naive R² | RMSSE % | R²≥0.85 |
|---|---|---:|---:|---:|:---:|
| **1–3일** | Stack | 0.8646 | 0.8074 | 83.8 | ✅ |
| **3–5일** | FlowAnchor | 0.7198 | 0.6622 | 91.1 | ❌ |
| **5–7일** | Stack | 0.5744 | 0.5433 | 96.5 | ❌ |
| **7–14일** | Stack | 0.3512 | 0.2640 | 93.9 | ❌ |
| **14–30일** | ExtraTrees | -0.1736 | -0.2281 | 97.8 | ❌ |
| **30–60일** | Stack | -0.5062 | -0.7786 | 92.0 | ❌ |
| **60–90일** | RandomForest | -0.8747 | -1.4134 | 88.1 | ❌ |

R² ≥ 0.85 달성 **1/7 구간**. RMSSE 는 naive(원점값 유지) 대비 정규화 오차로, 100 미만이어야 채택 가능하다. 전체 표와 각도별 단독 성능은 [`docs/METHANE_FORECAST_SYSTEM.md`](docs/METHANE_FORECAST_SYSTEM.md) §5.


## 운전 제어 권고

규칙표가 아니라 **채택된 모델에 반사실 질의**를 던진다. 조작단을 흔들어 다시 예측하고
ΔCH₄ 와 민감도를 직접 계산한다.

- 조작단 — 소화조 투입량 · 기질 배합비(음폐수/가축분뇨/음식물) · 소화조 온도 · 탈수 처리량
- **안전 게이트** — VFA/ALK ≥ 0.40, FAN ≥ 300 mg/L, pH < 6.8, OLR ≥ 4.0 중 하나라도
  걸리면 「부하 증대」 방향 권고를 봉쇄한다
- **모델이 naive 를 못 이기는 구간에서는 권고를 생성하지 않는다.** 화면에 그대로 표시한다

건강상태 경보는 문헌 절대임계가 아니라 **시설 자체 90일 기준선 대비 상대편차**로 낸다
(주의 ≥15 %, 위험 ≥25 %). 문헌 임계를 그대로 쓰면 이 시설에서 pH 98.4 %, OLR 86.2 % 가
발화해 경보가 죽는다.

## SCADA HMI + 백엔드

업로드된 Win32 스타일 산업용 HMI 디자인을 그대로 유지하고 하드코딩 값만 API 로 교체했다.

| 엔드포인트 | 내용 |
|---|---|
| `GET /api/health` `/api/bands` | 적재 상태 · 구간별 채택 모델과 성적 |
| `GET /api/overview` `/api/telemetry` | 신호등 · 게이지 · 계측 매트릭스 |
| `GET /api/trend` `/api/forecast` | 실측 이력 + 예측 + **95 % 경험 예측구간** |
| `GET /api/advisory` | 운전 제어 권고 + 안전 게이트 + 상태 진단 |
| `POST /api/simulate` | what-if — 조작단 변경 후 재예측 |
| `GET /api/alarms` | 경보 이력(상대편차 기준) |

`asof` 질의로 원점을 과거로 옮겨 「그날 이 화면이 무엇을 말했을 것인가」를 재현할 수 있다.

## 한계

1. **V(소화조 유효용적)는 외생 상수다.** 데이터로 식별되지 않는다(여섯 경로 전부 실패).
   OLR·HRT 는 V 가 상수이므로 투입 물량의 함수 변환일 뿐 독립 정보가 아니다.
2. **VS 물질수지는 이론 상한을 넘는다**(함축수율 ≈ 0.96 vs 이론 0.497). COD 기준으로는
   Y_COD = 0.298 로 정상이므로 VS 계측(DQ-08) 문제일 가능성이 높지만, 가스 유량계
   단위·보정 이력과 미기록 유입 유기물을 확인하기 전에는 확정할 수 없다.
3. **타깃 결측 39.4 % 가 성능의 실질 상한**이다. 이걸 푸는 것은 모델이 아니라
   연속 가스분석기다.
