# 01 · 무결성 검증 (Validation)

> ⚠ 본 데이터는 합성(예시) NGS RA 데이터입니다. TARGET(`ch4_yield`)은 문서화된 약한 신호로 주입된 합성 값입니다(`src/00_prepare_raw_data.py`).

## 1. RA 스케일 판별

- 판별 결과: **percent** (unit≈1 / percent≈100)
- 행 합 요약: min=100.000, median=100.000, max=100.000
- ✅ 스케일 일관성 확인. 이후 파이프라인은 내부적으로 행합=1 비율로 정규화하여 처리.

## 2. 행 합 편차 / 재정규화 로그

- 모든 시료의 행 합이 100±1 이내. 재정규화 불필요(파이프라인 내부 재정규화만 수행).

## 3. 음수 · NaN · 전(全)영 행/열

- 음수 값: 0 개
- NaN: 0 개
- 전영 시료(행): 0 
- 전영 taxa(열): 0 []
- (결측/이상은 발견만 보고하며 자동 대체하지 않음 — 사용자 판단 대상.)

## 4. 시료 ID ↔ metadata 대응
