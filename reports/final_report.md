# 최종 보고서 — 혐기성 소화조 16S RA → methane 예측 (정직한 검증)

## 0. 데이터·타깃 출처
- 특징: 16S RA(genus 집계, p=96), n=40 시료 = 10 site × 4 계절.
- 타깃: **methane(메탄생성량)**, targets.xlsx 2022년 3/6/9/12월 1일 값.
- ⚠ **핵심 가정**: 메탄생성량이 지역별로 다르나 현재 미준비 → **'모든 지역 동일'로 가정**. 따라서 타깃은 계절(날짜)에만 의존하고 10개 지역 값이 같다(예측 시뮬레이션).
- ⚠ 결측: 2022-06-01(전 컬럼 결측)은 최근접일 2022-05-31 로 대체(자동 아님, 명시).

## 1. 한계 먼저 (Limitations first)
- **유효 표본 = site 수 = 10** (반복측정: 같은 site×4계절). 시료 n=40 는 명목값.
- p/n(genus) = 2.40. 소표본 p≫유효n → 과적합·검정력 부족이 지배적 제약.
- 딥러닝/AutoML/대규모 스태킹 **배제**(유효 n=10 에서 검증 불가).
- 모든 성능은 **점추정 단독 금지** → CI·순열 p 동반.
- 🔴 **가정의 직접 귀결**: 타깃이 계절에만 의존하므로 **계절(날짜)만으로 완전 예측**되고, 마이크로바이옴이 계절을 넘어선 정보를 줄 여지가 원리적으로 없다. 아래 결과는 이 점을 확인한다.

## 2. 베이스라인 (모델보다 먼저)

| 베이스라인 | 내용 | R² (mean ± sd, LOGO) |
|---|---|---|
| B0_mean | 학습 fold 평균 | +0.000 ± 0.000 |
| B1_season | season 원-핫+sin/cos | +1.000 ± 0.000 |
| B2_alpha | 알파다양성 5종 | -0.019 ± 0.000 |
| B3_pcoa | Aitchison PCoA 3축 | -0.013 ± 0.000 |
| B4_random | 무작위 정규 특징 96개(동일 p), 5 seed | -0.093 ± 0.091 |

- **B1(계절)=R² +1.000**. 계절만으로 타깃이 (거의) 완전 예측됨 — 가정의 귀결.
- B4(무작위 특징)·B2·B3 는 ≈0 → 조성/다양성 자체는 계절 밖 신호 없음.

- 승자 **spls** 순열검정: 실제 R²=+0.826, **p=0.002** (귀무평균=-0.458).
- 승자 부트스트랩(site 단위) R² CI: +0.806 [+0.752, +0.855].
- ⚠ 순열 p 가 작아도 이는 **계절 신호**를 반영한다(마이크로바이옴 고유 신호 아님). 승자조차 B1(계절, R²=+1.000)을 **넘지 못한다** → taxa 는 계절 이상을 못 준다.

## 4. 탐색 그리드(낙관) vs 정직 — 편향 진단

| 모델 | 정직(중첩) | 탐색그리드(낙관·선택편향) | 무작위K-fold(누수) |
|---|---|---|---|
| spls | +0.806 | +0.826 | +0.795 |
| elasticnet | +0.648 | +0.704 | +0.584 |
| rf | +0.542 | +0.565 | +0.450 |
| pls | +0.506 | +0.599 | +0.457 |
| krr | +0.012 | +0.012 | -0.087 |
| gpr | +0.000 | +0.016 | -0.038 |
| hgb | +0.000 | +0.000 | -0.037 |
| svr | -0.008 | -0.008 | -0.144 |

- '누수(무작위K-fold)'≈'정직' → 타깃에 **site 구조가 없어**(지역 동일 가정) 그룹CV·무작위CV 가 일치. 즉 이 시뮬레이션에선 누수 격차가 사라진다(그룹 CV 는 여전히 방법론적 기본값).
- '탐색그리드'>'정직' 격차 = 소표본 승자의 저주(선택편향). 최종 수치로 쓰면 안 됨.

## 5. 절제 실험 (블록 기여)

| 조합 | 블록 | R² (mean±sd) |
|---|---|---|
| S1_design | design | +1.000 ± 0.000 |
| S2_alpha | alpha | -0.070 ± 0.000 |
| S3_taxa | taxa | -0.822 ± 0.000 |
| S4_taxa_alpha | taxa,alpha | -0.822 ± 0.000 |
| S5_full | taxa,alpha,beta,domain,design | +0.806 ± 0.000 |

- S5(전체) vs S1(계절) Wilcoxon p=0.002 (site=10).
- **S5 가 S1 을 유의하게 넘지 못함** → 마이크로바이옴은 계절 이상을 주지 못한다(가정의 귀결).

## 6. 안정적 특징 (70% 기준)

- 5 seed × 10 fold = 50회 순열 중요도 상위10 진입 빈도 집계.
- **70% 이상 안정 taxa 없음** → 안정적으로 예측에 기여하는 taxa 는 확인되지 않음(해석 금지).
- ⚠ 소표본 SHAP/단일 fit 중요도는 불안정 → 본 안정성 기준만 신뢰.

## 7. 부정적 결과 (작동하지 않은 것)
- 커널법(KRR/SVR)·트리(RF/HGB)는 대체로 음수/저조 R² — 소표본 p≫n 에서 불안정.
- 어떤 마이크로바이옴 모델도 **계절 베이스라인(B1)을 넘지 못함**.
- 누수 격차가 관측되지 않음 — 타깃에 site 구조가 없기 때문(지역 동일 가정).

## 8. 결론

- **현 표본·가정 하에서 마이크로바이옴 조성이 methane 을 '계절 이상으로' 예측한다는 증거가 없다.**
  - 근거: B1(계절)=R² +1.000 로 이미 완전 예측되고, 최고 마이크로바이옴 모델(**spls**, 정직 R²=+0.806)도 이를 넘지 못함. 절제 실험에서 S5≈S1.
- 이는 **'모든 지역 methane 동일' 가정의 직접 귀결**이다(타깃이 계절만의 함수). 따라서 이 결과는 마이크로바이옴의 무용을 증명하는 것이 아니라, **현 타깃 정의로는 판별 불가**함을 뜻한다.
- **권고**: 지역별 실측 methane(반복측정, 시료별 변동)을 확보해 타깃을 재정의해야 마이크로바이옴→methane 예측을 실제로 검정할 수 있다. 검증 프로토콜(그룹 CV)은 완화하지 말 것.
