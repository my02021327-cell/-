>
> 원문은 `docs/source/` 에 보존. 판정 근거는 `docs/REJECTED_REGISTRY.md`.

### 2.2 소화조는 CSTR — 투입일별 잔존율 차등

τ일 전 투입분의 조내 잔존율:

```
R(τ) = exp(−τ / SRT)
```

오늘 조 안의 물질은 오늘 들어온 것이 아니다. 일별 투입량에 이 커널을 합성곱해
**투입일별 잔존 슬러지 비율을 차등 적용**하라. 조 내 농도와 유출 슬러지 농도는 동일하다.

메탄으로 전환되는 몫은 분해속도 k를 곱한다:

```
h(τ) = k · exp(−(1/SRT + k) · τ)
```

전체 응답은 `전단커널_기질별 ⊛ 공통커널 ⊛ h(τ)` 의 직렬 합성곱이다.

### 2.3 SRT 정의 — 조내 VS ÷ 유출 VS

```
SRT [d] = 조내 VS [kg] / 유출 VS [kg/d]
```

가정: **SRT = HRT**, **소화액 밀도비 = 1**, **조내 농도 = 유출 농도**.

> **중요 — 이 정의는 물리적으로 옳지만 SRT를 데이터에서 만들어내지는 못한다.**
> 조내 농도 = 유출 농도이므로
> `SRT = (V × C_VS) / (Q_out × C_VS) = V / Q_out` 로 **VS 농도가 약분된다.**
> SRT=HRT·밀도1 가정에서 액상 물질수지상 `Q_out ≈ Q_in ≈ 197 t/d` 이므로,
> **실질적으로 유일한 미지수는 운전 중 유효용적 V 하나**다.
>
> | V | SRT |
> |---|---|
> | 4,000㎥ | 20.3일 |
> | 6,000㎥ | 30.5일 |
> | 8,000㎥ (설계) | 40.6일 |
>
> **지시** — V를 스크립트 최상단의 명시적 입력 상수로 두고(기본 8,000㎥, 운전 실적이 있으면 교체),
> SRT를 **추정 모수가 아니라 외생 파라미터**로 취급하라. 위 세 값 전부에 대해 결과를 산출하고
> 민감도를 보고한다. SRT를 데이터로 추정하려 시도하지 말 것 — §5.2에서 여섯 경로가 모두 실패했다.

## 3. 세 트랙 상세

### T1. 기질 물량 · 화학양론

**목적**: 반입비율에서 실제 투입된 3기질의 무게 수준을 복원하고, 화학양론으로 메탄 발생량을 예측한다.

1. **투입 물량 복원**
   `반입_총량_tpd × 반입비율_j` 로 기질별 반입 톤수를 만들고, §2.1의 기질별 전단 커널을 합성곱해
   **소화조 유입 톤수**를 얻는다. 여액저장조 합류 이후는 공통 커널이므로 순서를 지켜라
   (개별 커널 → 합류 → 공통 커널).
2. **화학양론 — Buswell 식**
   기질 CcHhOoNn 에 대해
   ```
   CcHhOoNn + (c − h/4 − o/2 + 3n/4)H₂O
        → (c/2 + h/8 − o/4 − 3n/8)CH₄ + (c/2 − h/8 + o/4 + 3n/8)CO₂ + nNH₃
   ```
   원소조성은 문헌값 범위를 쓰되 **가정치임을 명시**하라. 병행 경로로 COD 기반
   `CH₄ = 0.35 ㎥/kgCOD_제거` 를 계산해 두 경로가 일치하는지 교차확인한다.
3. **생분해도(BD) 도입**
   화학양론은 이론 최대치이므로 기질별 생분해도 BD_j (0<BD_j≤1)를 곱한다.
   BD_j 를 추정 대상으로 두되 **1을 넘으면 즉시 실패로 처리**하라.
4. **이탈 시 대응 (사용자 지시)**
   물질수지식이 과하게 이탈하면 억지로 맞추지 말고 새로운 해법으로 전환한다. 판정 기준과 전환 경로:

   | 이탈 지표 | 임계 | 전환 |
   |---|---|---|
   | BD_j > 1 | 물리적 불가 | 화학양론 강제를 풀고 θ_j 를 자유 계수로(단, §9 상한 유지) |
   | bdCOD > 총COD 상한 | §5.3 표 | 절편(미설명 항) 추가 후 재적합 |
   | 절편 > 실측의 15% | 구조적 결손 | T1 단독 예측을 중단하고 T2·T3 결합으로 이관 |

   **이탈 자체를 결과로 보고하라.** 억지로 맞춘 계수는 폐기 대상이다.

### T2. VS 물질수지

**목적**: 소화조에서 실제로 소비된 VS를 기준으로 메탄을 예측한다.

변수 정의 (밀도비 1, 조내농도=유출농도):

| 변수 | 계산 |
|---|---|
| 반입(유입) VS [kg/d] | 투입 톤수 × 산발효조 TS% × (VS/TS)_feed |
| 유출 VS [kg/d] | Q_out × 소화액 VS% × 1000 |
| 조내 VS [kg] | V × 소화액 VS% × 1000 |
| 소비 VS [kg/d] | 유입 VS − 유출 VS |

- `(VS/TS)_feed` 는 자료에 직접 없다. OLR 열(`OLR_kgVS_m3d`)과 V 로 역산하거나
  기질별 문헌값으로 가중하되 **어느 쪽을 썼는지 명시**하라.
- 예측식 기본형: `CH₄(t) = Y · 소비VS(t)` , 이어서 `CH₄(t) = c + Σ_j Y_j · 소비VS_j(t)` 로 확장
- **§4의 사전 점검 결과를 반드시 먼저 재현하고 시작하라.** 이 트랙은 시작하자마자
  이론 상한을 위반한다. 그 사실을 확인하는 것이 이 트랙의 첫 산출물이다.

### T3. 이화학 상태

**목적**: 소화조 또는 산생성조 내부 이화학 지표로 메탄을 예측한다.

- 후보 변수: 소화액 TS/VS, pH, 온도, VFA_A, ALK_A, VFA/ALK, NH₃-N, FAN, OLR, 산발효조 TS
- **누출 주의**: 이화학 지표는 대부분 동시점 관측이다.
  - **Nowcast(당일 추정)** 에서는 동시점 사용 가능
  - **Forecast(h일 앞)** 에서는 **반드시 lag를 걸어라.** 예측 시점에 알 수 없는 값이다.
- 결측이 많다(소화액 TS/VS 1,271일, NH₃-N 230일). 결측 처리 방식과 그것이 성능에 미치는 영향을
  별도로 보고하라. 결측 보간이 성능을 만들어내는 착시를 경계할 것.
- VFA/ALK 비, FAN 등은 **저해·불안정 지표**다. 메탄 예측력이 없어도 §6에 따라 폐기하지 말 것.

선행 분석에서 이미 계산했다. 같은 값이 나오는지 먼저 확인하고 시작하라.

| 항목 | 값 |
|---|---|
| 유입 VS (OLR×8,000㎥) | 8,848 kg/d |
| 유입 VS (TS부하×0.73) | 8,883 kg/d (두 경로 일치) |
| 유출 VS (Q×소화액VS%) | 2,171 kg/d |
| 소비 VS | 6,543 kg/d (VS 분해율 **76.1%**) |
| 실측 CH₄ | 6,802 ㎥/d |
| **함축 수율 (소비 VS 기준)** | **0.958 ㎥CH₄/kgVS_destroyed** |
| **함축 수율 (유입 VS 기준)** | **0.741 ㎥CH₄/kgVS_in** |

**이론·지침 상한과 비교**

- 이론 최대: 0.35 ㎥CH₄/kgCOD × 1.42 kgCOD/kgVS ≈ **0.50 ㎥CH₄/kgVS_destroyed**
  → 실측이 **1.9배 초과. 물리적으로 불가능하다.**
- 지침 메탄수율(투입 톤수 가중): 0.42~0.59 ㎥CH₄/kgVS_in → 실측이 상한의 **1.25배 초과**
- 지침 실측 VS 분해율 평균 59.7% vs 여기 76.1%

**해석과 지시** — 이 이탈은 §5.3의 "미설명 메탄 32%"를 완전히 독립적인 경로(회귀가 아닌 VS 물질수지)로
재확인한 것이며, 오히려 더 크게 나온다. 세 가지 중 하나이거나 복합이다:

1. **유입 VS 과소 계량** — 미기록 병합기질, 반송수·침출수 유기물, 외부 반입분
2. **CH₄ 계량 과대** — 유량계 단위(Nm³ vs ㎥), 온도·압력 보정, 메탄 농도 환산
> **[R-03] 삭제됨** — 1개 줄. 유입·유출·소비 VS 가 전부 V 와 무관하다(유입 VS=부하 원자료, 유출 VS=Q_out×소화액 VS%). V 는 조내 VS 와 SRT 에만 들어가므로 이탈 원인 후보에서 배제된다.

**T2는 이 이탈을 해소하기 전에는 절대수준 예측에 쓸 수 없다.** 다만 소비 VS의 **변동**이
메탄의 변동을 설명하는지(즉 기울기는 유효한지)는 별개 문제이므로, 절편을 허용한 상태에서
상대 예측력은 평가하라.

## 5. 검증된 사실 — 전제로 삼고 재검토하지 말 것

### 5.1 선행 물질수지는 항등식이었다

`TS제거율 ≡ 1 − 소화액TS/산발효조TS` 가 1,271일 전부에서 최대오차 5×10⁻⁵로 성립한다.
따라서 시트 05의 "역산 배출유량 197 t/d", "수지폐합 0.996", "SRT 12.2~40.8일 허용구간"은
모두 투입량을 대수적으로 되돌려 받은 것이며 유량 정보가 없다.
(역산배출유량 = 소화조투입량 완전일치 1,266/1,271일)

> 이는 §2.3의 SRT 정의를 부정하지 않는다. §2.3은 옳은 정의이고, 다만 **V를 외부에서 받아야** 한다는 뜻이다.

### 5.2 SRT는 이 자료로 식별되지 않는다 — 여섯 경로 전부 실패

| 경로 | 결과 |
|---|---|
| 고형물 물질수지 | 항등식 |
| 소화액 TS 동적응답 | R² 0.044 (소화액 TS 변동계수 8.2%로 응답 진폭 자체가 없음) |
| 알칼리도 / NH₃-N 추적자 | R² 0.071 / 0.059, 격자 상한 도달 |
| 메탄 프로파일 우도 | SRT 6→100일 평가 R² 변동 0.022 — 평탄 |
| 생분해성 COD 제약 | 무절편 사양이 만든 인공물 |
| 예측 성능 기준 선택 | CV-RMSE 전 구간 차이 0.52%, 폴드별 대응 t검정 **p ≥ 0.76** |

수학적 원인: 기질당 관측 가능한 양은 감쇠율 λ = 1/SRT + k 와 정상이득 G = θ·k·SRT/(1+k·SRT)
**두 개뿐**인데 미지수는 (θ, k, SRT) 셋이다. k를 고정해도 비식별성이 θ로 전가될 뿐이다.
→ **λ와 G로 재모수화해 추정하고, SRT는 사후 해석에서만 대입하라.**

### 5.3 측정 메탄의 약 32%가 추적 3기질로 설명되지 않는다

절편(θ≥0 제약, SRT 25일) ≈ **2,190 ㎥CH₄/d**, 실측 평균 6,834 ㎥/d의 **32%**.
무절편 모형은 이 상수를 커널이 가장 평탄한 가축분뇨(k=0.08/d)에 떠넘겨 θ를 3배 부풀린다.

TS 분해(유입TS부하 = Σ 투입톤_j × TS_j, 절편 없는 OLS)로 얻은 물리 상한:

| 기질 | TS % (95% CI) | 총 COD 상한 |
|---|---|---|
| 음폐수 | 7.51 (6.98~8.03) | 118.3 kgCOD/t |
| 가축분뇨 | 5.75 (4.85~6.65) | **77.2 kgCOD/t** |
| 음식물 | −1.85 (식별 안 됨) | 판정 불가 |

무절편 모형의 bdCOD(=θ/0.35): SRT 12일 148.9 / 25일 105.0 / 60일 80.9 — **전부 77.2 초과.**
절편을 넣으면 즉시 충족(25일에서 35.5).

> **[R-01] 삭제됨** — `5.4 전단 지연은 데이터가 유의하게 식별한다 — 유일한 예외`
>

## 6. 변수 채택 원칙 — 예측 모델 / 건강상태 점검 분기

소화조 운전에서 아무리 중요한 역할을 하는 변수라도,
**메탄 예측력이 없으면 예측 모델에 채택하지 않는다.** 대신 버리지 말고
**「소화조 내부 건강상태 점검 프로그램」** 으로 분류해 별도 산출물로 남겨라.

판정 절차:

1. 각 후보 변수에 대해 rolling-origin CV에서 **포함/제외 대응 t검정** 수행
2. p ≥ 0.05 이거나 ΔRMSE가 개선이 아니면 → **예측 모델에서 제외**
3. 제외된 변수는 다음 기준으로 건강상태 지표로 재배치:

| 지표 | 진단 의미 | 경보 기준(문헌·지침) |
|---|---|---|
| VFA/ALK | 산·알칼리도 균형, 과부하 조기경보 | 통상 0.3 초과 시 주의, 0.4~0.5 위험 |
| VFA 절대값 | 산 축적 | 급상승 추세 자체가 신호 |
| FAN (유리 암모니아) | 암모니아 저해 | 저해 개시 구간 문헌값 확인 후 설정 |
| NH₃-N | 질소 부하 | 상동 |
| pH | 완충 붕괴 | 6.8~7.6 이탈 |
| 온도 | 중온 안정성 | 설정치 ±1℃ 이탈, 센서 고장 플래그 병행 |
| OLR | 유기물 부하 | 지침 1.5~4.0 kgVS/㎥·d |

건강상태 프로그램 산출물: 일별 지표 + 이동추세 + 경보 플래그 + 이상구간 타임라인.
**메탄 예측 성능과 무관하게 독립적으로 평가·보고한다.**

## 7. 통합 앙상블 모델

T1·T2·T3에서 나온 예측기를 결합한다. 서로 다른 귀납 편향이 되도록 **최소 5개 계열**을 만들어라.

| 계열 | 기반 | 설명 |
|---|---|---|
| **M1** | T1 | 기계론적 합성곱 — 기질별 전단 커널 ⊗ 공통 커널 ⊗ h(τ), 화학양론/BD 제약, 절편 포함, 계수 ≥ 0 |
| **M2** | T1 | ADL(자기회귀 분포시차) — 기질 BMP 가중합 + 시차항. 조정속도에서 함축 HRT 역산해 문헌 대조 |
| **M3** | T2 | VS 물질수지 회귀 — 소비 VS·조내 VS·유출 VS를 변수로, 절편 허용 |
| **M4** | T1+T3 | 이산 lag 격자 + 트리(LightGBM/XGBoost). lag τ∈{0,1,2,3,5,7,10,14,20,30}일, 이동통계, 기질 구성비. SHAP으로 M1 물리구조와 대조 |
| **M5** | T2+T3 | 상태공간/칼만 — §5.3의 미설명 상수를 **상수가 아닌 느리게 변하는 상태**로 추적. 절편 궤적이 배합전환·개보수 시점과 정렬되는지 확인 |
| M6(선택) | 전체 | LSTM 또는 TFT. **M1~M5 완성 후에만** 시도하고, 개선이 유의하지 않으면 제외. 넣었다는 이유로 남기지 말 것 |

**결합**

- 메타 학습기: 비음수 가중 선형 결합 또는 얕은 ElasticNet 스태킹
- **메타 학습기 학습에도 rolling-origin 적용** — out-of-fold 예측만 사용. 누출 주의
- 단순 평균 / 성능가중 평균 / 스태킹 세 가지를 모두 보고하고 최선을 채택

## 8. 검증 프로토콜 — 위반 시 결과 전체가 무효

1. **확장창 rolling-origin 교차검증**이 표준. 초기 학습 365일, 예측창 90일, 원점 90일 전진 → 19폴드.
   학습셋은 **항상 검정점 이전 관측만** 포함한다.
2. **단일 hold-out(원본 `평가` 분할)으로 모델을 선택하지 말 것.**
   이 분할 하나로 고르면 최적 SRT가 ∞로 나와 교차검증(8일)과 방향이 정반대다.
   원본 시트 04의 "SRT를 늘릴수록 평가 R²가 좋아진다"도 같은 함정이다.
   hold-out은 최종 1회 보고용으로만 쓴다.
3. **무작위 k-fold 금지.** 일별 자기상관 자료에서 누출된다.
4. 모델 비교는 **폴드별 대응 t검정**으로 하고 ΔRMSE·SE·p를 함께 보고하라.
   평균 지표만 비교하고 "개선됐다"고 쓰지 말 것.
5. Forecast 트랙에서 동시점 내부 이화학 사용 금지(§3 T3).
6. 지표는 RMSE(주), MAPE, R²(부)를 모두 보고. 예측구간(불확실성)도 산출.

## 11. 금지사항

1. 소화조 용적 ÷ 반입량으로 SRT를 "추정"했다고 주장 — V는 외부 입력이며 추정 결과가 아니다
2. SRT를 데이터 추정 모수로 설정 — 비식별(§5.2)
3. 절편 없는 회귀를 최종 모델로 채택 — 미설명 항이 느린 기질로 전가된다
4. 단일 hold-out 또는 무작위 k-fold로 모델 선택
5. Forecast 트랙에서 동시점 내부 이화학 사용
6. 파생된 `투입톤_*`·`유입비율_*`을 원자료처럼 사용
7. 기질을 처음부터 통합 — 여액저장조 이전은 반드시 기질별 개별 커널
8. 물질수지 이탈을 계수 조정으로 은폐 — 이탈은 그대로 보고할 것
9. 예측력 없는 변수를 그냥 폐기 — §6에 따라 건강상태 지표로 재배치
10. 평균 지표만으로 "개선" 주장 — 대응검정 없이

2. **결과 JSON** — 트랙별·모델별·앙상블별 폴드 지표, 대응검정, 계수와 신뢰구간, 물리검사 통과 여부
3. **HTML 리포트** (단일 파일, 라이트/다크, 인터랙티브)
   - 트랙별 결과와 상호 비교
   - 앙상블 구성·가중치, 기준선 861.5 대비 대응검정
   - ablation: 전단 커널 / 절편 / 각 계열 / 각 변수군 제거 시 성능 변화
   - 잔차 진단: 시간·부하·계절·기질구성 대비 잔차, 자기상관
   - M5 시변 절편 궤적 — §5.3·§4 규명 단서
   - 물리 정합성 검사 표, VS 물질수지 이탈 정량
   - 예측구간 포함 시계열
4. **소화조 건강상태 점검 프로그램** (§6) — 별도 산출물. 지표·추세·경보 플래그·이상구간 타임라인

## 13. 작업 순서

1. 데이터 적재 + 품질 플래그 처리 + §9 재현 검사 통과 확인 — **여기서 막히면 이후가 전부 무효**
2. §4의 VS 물질수지 이탈 재현 — 같은 값이 나오는지 확인
3. rolling-origin 폴드 구성 고정 — 이후 **모든 모델이 동일한 폴드**를 쓴다
4. §5.5 기준선 4종 재현 (946.6 / 884.1 / 905.8 / 861.5)
5. T1 → T2 → T3 각각 독립 구축, 트랙별로 기준선 대비 대응검정
6. §6 변수 채택/배제 판정 및 건강상태 지표 분류
7. M1~M5 구축 → 앙상블 결합 3종 비교 → 채택
8. ablation + 잔차 진단 + 물리 검사
9. 리포트 + 건강상태 프로그램 작성

각 단계마다 중간 결과를 보고하라. 기준선을 못 넘는 계열이 있으면
**억지로 포함하지 말고 그 사실을 그대로 보고하라.** 앙상블에 넣어 성능이 떨어지면 빼는 것이 정답이다.
