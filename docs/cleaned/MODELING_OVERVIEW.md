# 영천 BGP 메탄생성 예측 — 모델링 설계 개요 (v2)

> 영천 통합바이오가스화시설(BGP)의 일별 운전데이터(2018-01-01 ~ 2023-09-17)를 대상으로
> **메탄생성량 예측**과 **소화조 건강상태 관제**를 수행하기 위한 설계 문서.
>
> **v2 개정** — 시설 공정도·6개년 워크북 정밀분석 문서 2종
> (`docs/reference/영천BGP_유기물처리계통설명서.md`, `docs/reference/영천BGP_AI참조문서.md`)과
> 정제 데이터셋(`data/영천BGP_MASTER_2018-2023.csv`, 61열·DQ 플래그 포함)을 반영해
> v1의 핵심 해석 오류를 정정하고 모델링 방향을 전면 수정했다.
> 본 문서의 수치는 참조문서 및 저장소 데이터 직접 검증 결과다.

## 1. 반응 공정 이해 (확정판)

### 1.1 계통 — 습식 · 중온 38℃ · 2상 · 병합소화 · 병렬 2기 CSTR

```
반입 3계열 (음폐수 58.8% / 가축분뇨 33.8% / 음식물 7.4% = 214.6 t/d)
   → 전처리 (협잡물 ~11.5 ㎥/d 반출)
   → 여액저장조 (완충)
   → 유기산화조 (산발효, pH 4.85, 스팀가온)      ← 2상의 1단
   → 혐기성소화조 #A 4,000㎥ ∥ #B 4,000㎥        ← 2상의 2단 (메탄생성)
        ├─ 바이오가스 10,460 ㎥/d (CH₄ 66.0%) → 탈황(H₂S 0ppm) → 발전 (자립률 113.6%)
        └─ 소화액 → 원심탈수 → 퇴비 9.35 t/d + 탈리액(폐수처리 계통)
```

| 제원/운전 | 값 | 의미 |
|-----------|-----|------|
| 소화조 용적 | 4,000㎥ × 2 = **8,000㎥** | 병렬 2기, A/B 대칭(r=0.927, 분담 51:49) |
| **HRT** | **40.5일** (5~95%: 32.5~55.6) | 통상 20~30일 대비 넉넉 — 체류시간 부족 아님 |
| **OLR** | **1.14 kg VS/㎥·d** (문헌 권장 1.5~4.0의 하단) | 부하 여유 — 과부하 아님 |
| 온도 | 중온 38℃ 설계 | pH_A 7.95 (CV 1.7%) |
| 설계 대비 | 바이오가스 105.9%, 메탄 **114.1%** (CH₄ 66.0% vs 설계 61.0%) | **설계 초과 달성 시설** |

### 1.2 상분리(2상)의 데이터 증거와 모델링 의미

- 산발효조 pH **4.85** vs 메탄조 pH **7.95** — 분포가 겹치지 않음. 설계대로 가수분해·산생성
  단계가 물리적으로 분리되어 있다.
- v1이 "음폐수가 저장 중 이미 산발효됐다"고 본 것은 오독 — **의도된 공정 단계**다.
- `acid_pH`(산발효조 pH)는 **가수분해·산생성 활성의 대리지표**로 유효: 바이오가스와
  r = −0.301 (다중회귀 t = −7.4). 단 6년간 4.84 → 5.14 상승 추세(τ=0.169) — 발효 유형
  변화 가능성, 주시 대상.

### 1.3 저류조 완충 — "반입 ≠ 투입"의 기전 확정

v1이 상관 부재(corr 0.187)로 추정한 것을 계통설명서가 기전으로 확정했다.

| | 반입량 | 소화조 투입 | 바이오가스 |
|---|:---:|:---:|:---:|
| 일요일 | **22.3 t/d** (급감) | 196.5 t/d | 10,539 ㎥/d |
| 주중 평균 | 233~261 t/d | 194~198 t/d | 10,229~10,422 ㎥/d |
| 변동계수 | **CV 46.3%** | **CV 17.3%** | — |

여액저장조가 반입 변동을 완전히 평활화한다. **기질별 반입량(음폐수/가축분뇨/음식물)은
당일 가스와 r ≈ 0.00 — 피처에서 제외**하고, 부하 변수는 `feed_AB`(소화조 실투입)만 쓴다.
반입 조성은 장기(암모니아 축적) 추세 분석에서만 의미를 갖는다.

### 1.4 생물학적 반응과 실질 병목 — 암모니아 저해

4단계 반응(가수분해→산생성→아세트산생성→메탄생성) 중 앞 2단계는 산발효조가 전담하고,
소화조는 아세트산생성+메탄생성에 특화되어 있다. **부하(여유)·체류시간(충분)·완충능(과잉)이
모두 정상인데 메탄 생산은 6년간 −8.1% 감소했다.** 소거법과 상관 사슬로 원인이 특정된다:

```
가축분뇨 비중 증가 (70.6 → 74.6 t/d)
  → TAN 축적: 3,337 → 4,913 mg/L (+104%, τ=0.571, p=5.0e-38)
  → 알칼리도 상승: 15,806 → 18,028 mg/L (NH₄HCO₃ 형성, ALK = 14,089 + 0.640×TAN)
  → pH 상승: 7.85 → 8.02
  → 유리암모니아(FAN) 증가: 306 → 585 mg/L   [FAN = TAN / (1+10^(pKa−pH))]
  → 메탄 함량 −4.5% · 메탄 생산 −8.1% · 반입톤당 메탄 −17%
```

- FAN 실측: 반응조 A 평균 **410 mg/L**, B **430 mg/L**. 명확한 저해 기준(300~600 mg/L)
  초과일이 **75~78%** — 6년 내내 저해 구간 운전. 붕괴하지 않은 것은 미생물 순치(acclimation)로
  설명된다.
- **VFA는 오히려 감소(−9.5%)** — 산성화가 아니라 메탄생성 단계 저해라는 결정적 증거.

> **[R-07] 삭제됨** — `1.5 VFA/알칼리도 신호등의 함정 (v1 관제 설계 폐기 사유)`
>
> 폐기 사유 자체는 옳지만 이미 반영이 끝나 문서에 남길 필요가 없다. 경보는 시설 자체 90일 기준선 대비 상대편차로 내고(주의 15%, 위험 25%), 문헌 절대밴드는 경보가 아니라 '설계·문헌 대비 위치' 진단으로만 병기한다 — `src/bgp/config.py` 의 RELATIVE_ALARM / GUIDELINE.
>
> 원문은 `docs/source/` 에 보존. 판정 근거는 `docs/REJECTED_REGISTRY.md`.

## 3. 전처리 파이프라인 (v2)

```
data/영천BGP_MASTER_2018-2023.csv (정제·플래그 완료, 2,086행 × 61열)
  → ① DQ 플래그 적용: 센서결함 T → NaN, 2023 ALK_B·VFA_ALK_B → NaN (이미 반영됨)
  → ② 랩 변수 결측 계층 처리
        L1 (≤3일, 주말): 선형보간 + mask=0
        L2 (4~7일): 보간 + mask=0
        L3 (>7일): 해당 시퀀스 샘플 제외
        타깃(biogas/CH4): 보간 절대 금지, 실측일만 라벨
  → ③ 파생: Δfeed_AB, biogas lag, FAN(측정 있는 구간), VFA_ALK_A(참고용)
  → ④ 시간순 분할: 학습 2018~2021 / 검증 2022~2023-09-17
```

**v1에서 삭제된 것**: `VS_in` EWMA(τ=5d) 커널 피처의 "1급" 지위 — persistence 구조(§4.1)가
지배하는 이상 수준(level) 커널 피처의 역할은 부차적이다. Δfeed가 그 역할을 대체한다.
`in_VS` 기반 부하 지표는 DQ-08로 절대값 신뢰 불가 — `in_TS` 사용.

## 4. 모델 설계 (v2 — 전면 수정)

### 4.1 왜 절대량 예측을 버리는가: persistence가 이미 이긴다

바이오가스/메탄 시계열은 ACF(1) = 0.916의 **확률보행에 가까운 구조**다 (차분 후 백색잡음
근접, 연주기성 없음). 관측 ACF는 이론 CSTR 감쇠 exp(−lag/HRT)와 형태가 일치한다 —
v1의 "τ≈5일 지수감쇠 커널" 발견과 같은 물리의 다른 표현이지만, 모델링 함의는 v1이 놓친
쪽이 결정적이다:

| 모델 | 검증구간 | R² | RMSE | MAE |
|------|----------|:---:|:---:|:---:|
| **Persistence** `ŷ(t)=y(t−1)` | biogas 2022~23 | **0.932** | 460 | 319 |
| Persistence + Δfeed `ŷ=y(t−1)+33.26·Δfeed` | biogas 2022~23 | **0.942** | 425 | 293 |
| 시계열 무시 수준회귀 `y=a+b·feed` | biogas 2022~23 | 0.266 | 1,510 | 1,312 |
| **Persistence (본 세션 재계산)** | **methane(저장소) 2023** | **0.877** | **384** | **261** |
| v1 RandomForest | methane 2023 | 0.588 | 702 | 565 |
| v1 Ensemble (NNLS) | methane 2023 | 0.538 | 743 | 612 |

**v1의 모든 모델이 전일값 하나만 쓰는 베이스라인에 미달한다.** v1 파이프라인은 lag-1
타깃 자체를 피처로 쓰지 않았고 절대량을 직접 회귀했기 때문이다. 절대량 R²는 자기상관을
그대로 흡수해 **높아도 착시, 낮으면 베이스라인 미달**인 지표다.

> **[R-09] 삭제됨** — `4.2 타깃 재정의`
>
> 주 타깃을 Δ(1일 차분)으로 재정의하는 설계. h=1 은 persistence 가 R²=0.932 로 이미 이기는 구간이고 차분은 ACF(1)=−0.059 로 예측 가능성 자체가 없다. 지평 구간별 수준 예측(1–3/3–5/5–7/7–14/14–30/30–60/60–90일)으로 교체했다.
>

### 4.5 앙상블 구조의 재배치

v1의 이질적 base + NNLS 스태킹 골격은 유지하되, **persistence 잔차 위에서** 작동시킨다:

```
1단: ŷ₀(t) = y(t−1) + β·Δfeed_AB(t)          ← 물리 베이스라인 (해석 가능, 항상 병기)
2단: Δ잔차 = y(t) − ŷ₀(t) 를 RF·GBM·(선택) LSTM으로 학습
      피처: T2 상태변수(in_TS, acid_pH, ALK_A, VFA_ALK_A, CH4_pct) + 요일 + 마스크
3단: NNLS 비음수 결합 (실패 모델 자동 배제 성질 유지)
```

기대치 관리: persistence+Δfeed가 이미 R² 0.942이므로 2단이 더할 수 있는 것은 크지 않다
(상한 ~0.05). **모델의 실질 가치는 예측 정확도가 아니라 §5의 잔차 관리도** — "물리적으로
설명되지 않는 이탈"의 탐지에 있다.

## 5. 건강상태 관제 재설계 (v1 신호등 폐기 → 다층 규칙)

이상탐지의 현실: 6년 2,191일 중 다지표 동시 이상 4일, 확인된 공정 이벤트 1건(2018-09-10),
운전일지 라벨 0건 → **지도학습 불가. 규칙 기반 + 잔차 관리도로 설계한다.**

| 레벨 | 지표 | 임계 | 우선순위 | 비고 |
|------|------|------|:---:|------|
| **L1** | **FAN** = f(NH₃-N, pH, T) | > 300 mg/L | **최상** | 근본원인 직결. **NH₃-N 측정 재개가 전제** |
| L2 | VFA_ALK_A 3일 이동평균 | > 0.30 | 중 | 급성 산성화용으로만. 둔감(6년간 0.4% 초과) + §1.5 함정 주의. **2023년 B계열 사용 금지** |
| **L3** | persistence+Δfeed **잔차 \|z\|** | > 3σ, 2일 연속 | 상 | "투입으로 설명 안 되는 가스 급변" — 순치 붕괴·저해 급진행의 일반 탐지기 |
| L4 | 알칼리도 3일 연속 하락 + VFA 상승 동시 | 콤보 | 중 | 완충능 실소진 전조 |

v1 신호등(4색 밴드)과의 차이: 단일 지표(VFA/Alk)의 색이 아니라 **서로 실패 모드가 다른
4개 규칙의 합성**으로 판단한다. 특히 이 시설의 지배적 실패 모드(만성 암모니아 저해)는
L1 없이는 어떤 지표로도 보이지 않는다.

## 부록 B. FAN 계산식 (Anthonisen)

```python
def calc_FAN(TAN_mgL, pH, T_celsius=38.0):
    """유리암모니아 (mg/L as N). 결측 온도는 38.0 대입(센서결함 회피)."""
    pKa = 0.09018 + 2729.92 / (T_celsius + 273.15)
    return TAN_mgL / (1 + 10 ** (pKa - pH))
# 임계: <150 무영향 / 150-300 저해 시작 / 300-600 명확한 저해 / >600 심각
```
