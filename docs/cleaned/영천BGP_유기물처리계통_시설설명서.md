# 영천 BGP 유기물 처리 계통 설명서

본 문서는 시설 공정도에 기재된 **설계 정보**와, 6개년 운영데이터에서 산출한 **실측 성능**을 나란히 놓고 기술합니다. 폐수처리설비는 유기물 계통의 종착점(탈리액 인계)으로만 언급하고 상세는 다루지 않습니다.

---

## 0. 계통 개요

```
[반입 3계열]
  음식물류폐기물(고상) ──┐
  음식물폐수(액상)    ──┼─→ [전처리설비] ─→ 여액저장조
  가축분뇨(액상)      ──┘                      │
                                              ↓
                                    [유기산화조] (산발효, 스팀가온)
                                              ↓
                                    [혐기성소화조] #A 4,000㎥ + #B 4,000㎥
                                       ├──── 소화가스 ─→ [소화가스 이용설비]
                                       ↓
                                    [소화액 저류조]
                                              ↓
                                    [원심탈수기]
                                       ├─ 탈수케이크 ─→ [퇴비화설비] ─→ 퇴비 9.35 t/일
                                       └─ 탈리액 ────→ (폐수처리설비, 본 문서 범위 밖)

[부산물] 협잡물 ─→ 협잡물 컨테이너 ─→ 반출
[부대] 탈취설비 (자원화동 + 퇴비화설비 + 폐수처리설비 3계통 통합 처리)
```

**공정 유형**: 습식(wet) · 중온(mesophilic, 38℃) · **2상(two-phase)** · 병합소화(co-digestion) · 병렬 2기 CSTR

## 1. 반입 계통 (3계열 분리)

공정도상 반입은 **세 갈래로 완전히 분리**되어 있으며, 각각 다른 전처리 경로를 탑니다.

| 계열 | 성상 | 전처리 경로 | 실측 반입량 | 비율 |
|---|---|---|---|---|
| **음식물류폐기물** | 고상 | 저장호퍼 → 파봉파쇄기 → 용융혼합처리기 | 15.9 t/일 | 7.4% |
| **음식물폐수** | 액상 | 스트레이너 (협잡물 0.5 ㎥/일 분리) | 125.7 t/일 | **58.8%** |
| **가축분뇨** | 액상 | 협잡물종합처리기 (협잡물 2.6 ㎥/일 분리) | 73.0 t/일 | 33.8% |
| **합계** | | | **214.6 t/일** | 100% |

> 실측값은 2018–2023 전기간 평균. 설계 반입량 209.05 t/일 대비 **101.6%** (2018–2022 기준 212.4 t/일).

### 계통 설계상 주목할 점

- **음폐수가 주 기질(58.8%)** 입니다. 명칭은 "음식물류폐기물 자원화시설"이지만, 실제 유입 질량의 6할은 재활용시설에서 나오는 **음폐수(FRW, food waste-recycling wastewater)** 입니다.
- 고상 음식물은 전체의 7.4%에 불과하므로, 파봉·파쇄 라인의 부하는 낮습니다.
- **가축분뇨가 33.8%** 로 상당한 비중입니다. 이것이 후술할 암모니아 문제의 근원입니다(§7).

## 2. 전처리설비

### 2.1 고상 라인 (음식물류폐기물)

```
음식물수집운반차 → 음식물 저장호퍼 → 파봉파쇄기 → 음식물용융합처리기 → 미세협잡물 제거기 → 여액분리기
```

| 단위공정 | 기능 |
|---|---|
| 저장호퍼 | 반입 완충, 정량 공급 |
| 파봉파쇄기 | 봉투 파봉 및 입도 축소 |
| 용융합처리기 | 가온·혼합으로 유기물 가용화, 협잡물 부상 유도 |
| 미세협잡물 제거기 | 잔류 미세 이물질 제거 |
| 여액분리기 | 고액분리 — 여액은 여액저장조로, 고형 협잡물은 협잡물 라인으로 |

### 2.2 협잡물 처리 지선

전처리 각 단계에서 분리된 협잡물이 별도 계통으로 모입니다.

```
부유협잡물제거기 → 드럼스크린 → 협잡물탈수기 → 협잡물 컨테이너 → 협잡물 반출
비협잡물제거기 ────────────────────↗
```

**공정도 기재 협잡물 발생량**

| 발생원 | 양 |
|---|---|
| 협잡물탈수기 계열 | 7.39 ㎥/일 |
| 비협잡물제거기 계열 | 1.0 ㎥/일 |
| 음식물폐수 스트레이너 | 0.5 ㎥/일 |
| 가축분뇨 협잡물종합처리기 | 2.6 ㎥/일 |
| **합계** | **약 11.5 ㎥/일** |

협잡물은 소화 대상에서 제외되어 반출됩니다. 반입량 대비 약 5% 수준이 초기 단계에서 걸러집니다.

### 2.3 여액저장조

전처리를 통과한 액상 유기물이 모이는 완충조입니다. 운영데이터에도 `여액저장조 / pH · TS(%) · VS(%)` 항목이 존재하며, 결측률 11.5%로 비교적 성실히 측정되고 있습니다.

**이 조가 공정 안정성에 결정적입니다.** 데이터가 이를 증명합니다.

| 요일 | 월 | 화 | 수 | 목 | 금 | 토 | **일** |
|---|---|---|---|---|---|---|---|
| 반입량 (t/일) | 261.2 | 255.7 | 236.5 | 236.1 | 233.0 | 203.3 | **22.3** |
| 소화조 투입 (t/일) | 194.4 | 196.7 | 197.7 | 197.5 | 197.4 | 198.0 | **196.5** |
| 바이오가스 (㎥/일) | 10,315 | 10,229 | 10,330 | 10,358 | 10,357 | 10,422 | **10,539** |

일요일 반입이 22 t으로 급감해도 **소화조 투입은 196.5 t/일로 전혀 흔들리지 않습니다.** 여액저장조가 반입 변동을 완전히 평활화합니다.

- 반입량 변동계수 CV = **46.3%**
- 소화조 투입량 변동계수 CV = **17.3%**

## 3. 혐기성 소화설비

### 3.1 유기산화조 (산발효조, Acidogenic Reactor)

공정도상 **스팀 가온 라인**이 연결되어 있습니다. 가수분해·산생성 단계를 물리적으로 분리한 **2상 시스템의 1단**입니다.

| 항목 | 실측값 (n) | 비고 |
|---|---|---|
| pH | **4.85** (평균) / 4.64 (중앙) | 5%분위 3.97, 95%분위 5.93 |
| TS | 6.25% | |
| VS | 4.64% | |
| COD(cr) | 143,875 mg/L | 고농도 유기물 |

**산발효조 pH 4.85와 메탄조 pH 7.95의 분포는 서로 겹치지 않습니다.** 상 분리가 설계대로 작동하고 있음을 데이터가 확인해 줍니다.

> **공정 해석**: 산발효조 pH는 가수분해·산생성 활성의 대리지표(proxy)로 쓸 수 있습니다. 실제로 바이오가스 발생량과 **r = −0.301** (p=5.3e-28)의 음의 상관을 보입니다 — 산발효가 활발할수록 pH가 낮아지고 후단 메탄생성이 늘어납니다.
>
> 다만 6년간 산발효조 pH가 4.84 → 5.14로 **상승 추세**(Kendall τ=0.169, p=3.8e-17)입니다. 발효 유형(butyrate / mixed-acid 등)이 변하고 있을 가능성이 있어 주시가 필요합니다.

### 3.2 혐기성소화조 (Methanogenic Reactor)

| 제원 | 값 | 출처 |
|---|---|---|
| 반응조 #A 유효용적 | **4,000 ㎥** | 워크북 `Data 계산` 시트 |
| 반응조 #B 유효용적 | **4,000 ㎥** | 동일 |
| **총 용적** | **8,000 ㎥** | 동일 |
| 구성 | 병렬 2기 CSTR | 공정도 |
| 온도 | 중온 38℃ | 설계 기준 35~38℃ |

**운전 실적 (2018–2023)**

| 지표 | 실측 | 비고 |
|---|---|---|
| 소화조 투입 | 196.9 t/일 | 설계 A·B 각 104.525 ㎥/일 |
| **HRT** | **40.5일** (5~95%: 32.5~55.6) | 음식물류 AD 통상 20~30일보다 김 |
| 일 회전율 | 2.47%/일 | 하루에 내용물의 2.5%만 교체 |
| **OLR** | **1.14 kg VS/㎥·일** | 문헌 권장 1.5~4.0의 **하단** |
| pH | 7.95 (CV 1.69%) | |
| VFA | 2,907 mg/L | |
| 알칼리도 | **17,026 mg/L as CaCO₃** | 하수슬러지 소화조의 3~5배 |

| COD 제거율 | 80.4% | |

**A/B 반응조 대칭성**: 상관 r = 0.927, A/B 가스 비율 중앙값 1.039 — 두 반응조는 사실상 동일 조건 병렬 운전입니다.

## 4. 소화가스 이용설비

### 4.1 계통

```
혐기성소화조 → GAS HOLDER → 제습장치 → (중간 저장) → 탈황설비 ─┬→ [상시] 가스발전기
                                                              ├→ [비상시] FLARE STACK
                                                              └→ [비상시] 온수보일러
```

### 4.2 설계 대비 실적 — 초과 달성

**공정도 기재 설계값**

| 항목 | 설계 |
|---|---|
| 바이오가스 발생량 | **9,876 Nm³/일** |
| 메탄가스 발생량 | **6,024.36 Nm³/일** |
| → 설계 메탄 함량 | **61.0%** |

**실측 (2018–2022 완전연도 평균)**

| 항목 | 실측 | **설계 대비** |
|---|---|---|
| 바이오가스 | 10,460 ㎥/일 | **105.9%** |
| 메탄 생산 | 6,874 ㎥/일 | **114.1%** |
| 메탄 함량 | **66.0%** | 설계 61.0% 대비 +5.0%p |

**이 시설은 설계 성능을 상회하고 있습니다.** 특히 메탄 함량이 설계보다 5%p 높아, 메탄 생산량 기준으로는 설계 대비 114%입니다.

> **단위 주의**: 설계값은 Nm³(표준상태 환산), 실측값은 운영일지 기록값(환산 여부 불명)입니다. 엄밀한 비교에는 온도·압력 보정이 필요하므로, 위 백분율은 개략 지표로 보시기 바랍니다.

운영일지 년계 기준 (2022년):

**발전량이 사용량을 초과하는 에너지 순생산 시설**입니다. 미이용 8.5%는 플레어 소각 또는 저장 손실로 추정됩니다.

### 4.4 탈황

운영일지 실측 기록:

| 기준일 | 탈황 전 H₂S | 탈황 후 H₂S |
|---|---|---|
| 2019-04-10 | 80 ppm | **0 ppm** |
| 2020-11-11 | 70 ppm | **0 ppm** |
| 2021-12-31 | 50 ppm | **0 ppm** |

탈황설비는 완전히 작동합니다. 원가스 H₂S가 50~80 ppm으로 낮은 것은 **철염 투입**(2022년 293톤/년) 때문으로, 소화조 내에서 황화물을 미리 침전시키는 방식입니다.

> **주의**: 운영관리 워크북 `Data` 시트의 H₂S 컬럼은 0.01%(100 ppm) **고정 가정치**이며 실측이 아닙니다. 위 실측값과 다르므로 데이터 분석 시 사용하지 마십시오.

## 5. 퇴비화설비

공정도에서 확인되는 계통으로, 소화 잔재물을 자원화하는 후단 라인입니다.

### 5.1 계통

```
소화액 저류조 → 원심탈수기 ─┬─ 탈수케이크 → 슬러지 저장호퍼 → 혼합기 → 후부숙조 → 퇴비장 컨테이너 → 퇴비 출하
                            └─ 탈리액 → (폐수처리설비)
```

### 5.2 투입 약품 및 산출

| 항목 | 공정도 기재 |
|---|---|
| 세척수 | 4 ㎥/일 |
| POLYMER (탈수 응집제) | 36.63 ㎥/일 |
| **퇴비 생산** | **9.35 톤/일** |

**실측 탈수량**: 312.1 t/일 (n=1,918)

### 5.3 물질 흐름 해석

```
반입 214.6 t/일  →  소화조 투입 196.9 t/일  →  탈수 312.1 t/일  →  퇴비 9.35 t/일
```

탈수량(312 t/일)이 소화조 투입량(197 t/일)보다 큰 것은, 탈수기가 **소화액 + 슬러지 저류조 탈리액을 혼합 처리**하기 때문입니다(운영데이터 컬럼명이 `혼합슬러지 탈리액(소화조+슬러지 저류조 탈리액)`으로 이를 명시합니다).

반입 214.6 t → 퇴비 9.35 t이므로, **질량 기준 약 4.4%가 고형 퇴비로 회수**되고 나머지는 가스화 또는 액상으로 후단 이송됩니다.

### 5.4 후부숙(post-maturation)

공정도상 후부숙조가 2단으로 구성되어 있습니다. 혐기소화 잔재물은 그대로는 부숙도가 낮으므로, 호기적 후숙 과정을 거쳐 퇴비 기준을 충족시킵니다. 이 구간의 운전 데이터는 운영관리 워크북에 포함되어 있지 않습니다.

## 6. 탈취설비 (부대)

3개 계통의 악취를 통합 처리합니다.

```
자원화동 ──┐
퇴비화설비 ─┼→ 벤츄리 스크러버 → 3단 약액세정탑 → 배출
폐수처리설비┘
```

혐기소화 자체는 밀폐계이므로 악취원이 아니고, **전처리(자원화동)와 퇴비화 후부숙 구간이 주 발생원**입니다.

## 7. 계통 통합 진단 — 병목은 어디인가

6년 데이터를 공정 계통 위에 얹으면 진단이 명확해집니다.

### 7.1 정상 작동 중인 부분

| 단위 | 근거 |
|---|---|
| 여액저장조 완충 | 반입 CV 46.3% → 투입 CV 17.3%, 일요일 반입 급감에도 가스 무변동 |
| 상 분리 | 산발효 pH 4.85 vs 메탄조 pH 7.95, 분포 미중첩 |
| 완충능 | 알칼리도 17,026 mg/L, VFA/Alk 0.172, 위험구간 0.4% |
| A/B 병렬 균형 | 상관 r=0.927, 가스 분담 51:49 |
| 가스 이용 | 이용률 91.5%, 전력 자립률 113.6% |
| 탈황 | 후단 H₂S 0 ppm |
| 설계 대비 성능 | 바이오가스 105.9%, 메탄 114.1% |

### 7.2 실질 제약 — 암모니아 저해

부하(OLR 1.14, 여유) · 체류시간(HRT 40.5일, 충분) · 완충능(Alk 17,000, 과잉) 모두 문제가 없습니다. 소거법으로 남는 것은 하나입니다.

```
가축분뇨 33.8% 비중 (70.6 → 74.6 t/일 증가)
        ↓
TAN 축적: 3,337 → 4,913 mg/L (+104%, τ=0.571, p=5.0e-38)
        ↓
알칼리도 상승: 15,806 → 18,028 mg/L (+19.8%, τ=0.622)
        ↓
pH 상승: 7.85 → 8.02 (τ=0.261, p=3.9e-38)
        ↓
유리암모니아(FAN) 지수적 증가: 306 → 585 mg/L
        ↓
메탄 함량 −4.5% · 메탄 생산 −8.1% · 반입톤당 메탄 −17%
```

**FAN 실측 (Anthonisen 식 기준)**

| 반응조 | TAN 평균 | FAN 평균 | FAN>150 (저해 시작) | FAN>300 (명확한 저해) |
|---|---|---|---|---|
| #A | 3,832 mg/L | **410 mg/L** | 98.7% | 75.1% |
| #B | 3,997 mg/L | **430 mg/L** | 98.3% | 77.8% |

**6년 내내 명확한 저해 구간(300~600 mg/L)에서 운전되어 왔습니다.** 붕괴하지 않은 것은 미생물 군집이 암모니아 내성 종으로 순치(acclimation)되었기 때문으로 판단됩니다.

### 7.3 관리 지표의 함정

| 연도 | VFA/Alk (관리지표) | 메탄 생산 (실제 성능) |
|---|---|---|
| 2018 | 0.21 | 7,080 ㎥/일 |
| 2019 | 0.18 | 7,346 |
| 2020 | 0.16 | 6,937 |
| 2021 | 0.17 | 6,568 |
| 2022 | **0.16** | **6,430** |

**VFA/Alk는 "개선"되는데 메탄은 계속 줄어듭니다.** 분모인 알칼리도가 저해물질(암모니아) 때문에 커진 결과입니다.

기전상 암모니아성 질소는 CO₂와 결합해 중탄산암모늄(NH₄HCO₃)을 형성하고, 이것이 총알칼리도로 측정됩니다. 실측 회귀도 이를 뒷받침합니다.

```
ALK_A = 14,089 + 0.640 × NH₃-N     (r=0.587, R²=0.345, p=1.0e-22, n=230)
```

즉 **TAN 1,000 mg/L 증가당 알칼리도가 640 mg/L 증가**합니다. 이 시설에서 VFA/Alk를 단독 관리 기준으로 쓰면, 성능이 서서히 무너지는 동안 계기판은 계속 초록불을 표시합니다.
