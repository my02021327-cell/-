# 모델링을 실제로 해보고 알게 된 것

> 이 문서는 요약이 아니라 **교훈집**이다. 입력 문서에 없었거나, 있었지만 데이터로 확인해보니
> 달랐던 것만 담는다. 각 항목은 **무엇을 알았나 / 어떻게 알았나(근거 수치) / 무엇이 달라지나**

>
> 근거는 전부 재현 가능하다:

## A. 이 시설에 대해 알게 된 것

### A1. 여액저장조는 수동 CSTR 이 아니다 — 조작되는 완충조다 🔴 가장 큰 발견

- **알게 된 것**: 반입에서 전단 커널로 소화조 투입을 재구성하면 실측과 **r=0.548** 에 그친다.
  커널이 상관을 0.203 → 0.548 로 크게 올리지만 실측을 대체하지 못한다.
- **어떻게**: 일요일 반입이 **22.3 t/d** 로 급감해도 투입은 **196.5 t/d** 로 흔들리지 않는다.
  반입 CV 46.1% → 투입 CV 17.3%. 지수 RTD 는 원리적으로 "일정하게 유지되는 출력"을
  만들어낼 수 없다 — 운전원이 투입을 일정하게 유지하도록 조작하기 때문이다.
- **달라지는 것**: 구동 변수를 **실측 투입(`feed_AB`)** 으로 바꿨다. 전단 커널 자체를 제거해
  모델이 더 단순해졌고, 아래 A2 가 동시에 풀렸다.

> **일반화**: 완충조가 "설계상 CSTR" 이라고 해서 RTD 모델이 맞는 것이 아니다.
> **제어되는 조는 물리 모델이 아니라 제어 규칙을 따른다.** 재구성 값을 쓰기 전에
> 실측과의 상관을 반드시 확인할 것.

### A2. 미설명 메탄(절편 37.6%)은 느린 분해가 아니다 🔴 방향을 바꾼 발견

- **알게 된 것**: 절편이 실측의 34~43% 를 가져가는데, 이것은 **동역학으로 줄지 않는다.**
- **어떻게**: 속분해/난분해 2풀을 만들어 검증했다. 미설명분이 추적 기질의 난분해 꼬리라면
  절편을 없앤 자리를 부하 연동 느린 풀이 메워야 한다. **메우지 못한다** —
  2풀+절편 787.3 → **절편 제거 935.9 (+149 ㎥/d)**. 느린 풀 열이 상수가 아닌데도(CV 16~20%) 그렇다.
- **달라지는 것**: **커널을 더 정교하게 만드는 방향은 낭비다.** 남은 후보는 계량 문제
  (미기록 유입 유기물 / 가스 유량계 단위·보정)뿐이다. 모델링이 아니라 **계량 감사**가 답이다.

### A3. VS 물질수지 이탈은 용적(V)으로 설명되지 않는다

- **알게 된 것**: 유입·유출·소비 VS 가 **전부 V 와 무관**하다. V 는 조내 VS 와 SRT 에만 들어간다.
- **어떻게**: 유입 VS = 부하 원자료, 유출 VS = Q_out × 소화액 VS%. 어디에도 V 가 없다.
- **달라지는 것**: PROMPT §4 가 든 이탈 원인 3후보 중 **"V 또는 소화액 VS% 오류"가 배제**되고
  둘만 남는다. 감사 범위가 좁혀졌다. (함축수율 0.99 vs 이론 0.497 = **1.99배** 는 그대로 남는다)

### A4. 타깃 결측은 '유량'이 아니라 '농도'에 있다

- **알게 된 것**: `biogas_AB_m3d` 결측 **0%**, `CH4_pct` 결측 **39.4%(821일)**.
  CH₄ = 유량 × 농도이므로 타깃 결측의 원인은 하나뿐이다.
- **어떻게**: 열별 결측률 직접 확인. 그리고 농도는 매우 매끄럽다 — ACF(1)=**0.968**,
  일간 변화 SD **0.86 %p**, 결측 간격 중앙값 **2일**, **91.4%가 3일 이하**.
- **달라지는 것**: 보간으로 라벨을 만들 필요가 없다. **유량을 병행 타깃으로** 두면
  폴드가 18 → **19** 로 늘고 주말 포함 전 구간에서 검증된다. 결측을 우회하는 게 아니라 없앤다.

### A5. "주말 CH₄% 가 낮다"는 근거가 없다

- **알게 된 것**: 주말 평균 61.6 vs 주중 66.0 은 **연도 교란**이다.
- **어떻게**: 주말 관측이 **6건**뿐이고 그중 **5건이 2021년**인데, 2021년은 주중 평균도
  62.2 로 6년 중 최저다. Mann-Whitney p=0.001 은 표본이 아니라 교란이 만든 값이다.
- **달라지는 것**: 짧은 간격 재구성의 걸림돌이 하나 사라졌다. 다만 재구성은 여전히
  **보고용으로만** 쓰고 평가에는 쓰지 않는다.

### A6. 반응조 관성의 정보는 약 2주에서 소진된다

- **알게 된 것**: biogas 전 구간(결측 0%) persistence R² — h=1 **0.831**, h=7 0.340,
  h=14 **0.011**, h=30 −0.488, h=90 −1.489.
- **어떻게**: 지평별 직접 계산. 결측 없는 계열이라 편향이 없다.
- **달라지는 것**: "관성을 쓸까 말까"가 아니라 **"h≤14 에서 쓴다"** 로 질문이 바뀐다.

### A7. 열역학 위반은 연도별로 극단 편중돼 있다

- **알게 된 것**: 전체 14.2% 지만 **2018년은 72.0%**(유효 n=50), 2023년 27.3%,
  2021년은 0.9% 로 가장 깨끗하다.
- **달라지는 것**: **2018년은 Y_COD 기준선 산출에서 제외**해야 한다.
  기존 `flag_regime_2018`(가스 고분산)과는 **다른 사유**(COD 계측 신뢰성)다.

## B. 모델링 방법에 대해 알게 된 것 (전이 가능)

### B1. 관성은 '수준'이 아니라 '잔차'에 붙여야 한다 ⭐ 핵심

- **알게 된 것**: 같은 직관이 붙이는 자리에 따라 정반대 결과를 낳는다.
  - 수준에 붙임(경험식 `C_base·MA30`) → **예측의 63.4%가 자기회귀항**이 되고 공정 설명력 상실
  - 잔차에 붙임(`ŷ = ŝ·ρ̄^exp(−h/τ)`) → h→0 이면 persistence, h→∞ 이면 순수 기질 모델로 수렴
- **어떻게**: 두 형태를 동일 폴드에서 실행. 잔차 형태는 h=1–3 **+46.3%**, 4–7 +29.8%,
  8–14 +15.6%, h≥15 소멸.
- **달라지는 것**: `y_lag` 금지 규칙과 관성 활용이 **양립한다**. 금지 대상은 자유 회귀계수이지
  물리적 감쇠 되먹임이 아니다.

> **왜 안전한가**: 보정항이 잔차에 붙으므로 계수를 부풀려 R² 를 만드는 경로가 없다.
> ŝ 가 나쁘면 ρ̄ 가 커질 뿐 성능은 좋아지지 않는다.

### B2. 시간상수는 자유 파라미터가 아니다 — 물리 상한을 걸어라

- **알게 된 것**: τ 격자를 30일까지 열어두면 내부 검증이 τ=30 을 골라 장기에서 손해를 본다
  (Δ−14.5, **p=0.47 비유의**). CSTR 세척 한계 **1/(1/SRT+k) ≤ 17.3일**(SRT 25) 안으로
  제한하자 **Δ−30.2, p=0.033 으로 유의**해졌다.
- **달라지는 것**: 하이퍼파라미터에 물리 상한이 있으면 **반드시 격자에 반영**한다.
  최적화기는 물리를 모른다.

### B3. NNLS 계수 0 은 "기여 없음"이 아니라 "식별 안 됨"이다 ⚠️ 오독하기 쉬움

- **알게 된 것**: 가축분뇨 θ=0.000 을 "가축분뇨가 메탄을 안 낸다"로 읽으면 안 된다.
  구동 변수를 바꾸자 **0 → 11.791** 로 복원됐고 절편도 42.9% → 34.2% 로 줄었다.
- **어떻게**: 반입 구동에서는 전단 커널이 세 기질 응답을 비슷하게 뭉개 분리가 안 됐다.
  투입 구동 설계행렬의 열간 상관은 낮다(음폐수~가축분뇨 r=0.039).
- **달라지는 것**: 경계값 계수를 보면 **먼저 설계행렬 공선성을 의심**한다.
  외부 모델(경험식)이 Y_m=5.31 을 유지했다는 사실이 우리 쪽 문제임을 알려줬다.

### B4. 물리 제약은 공짜에 가깝다 — 사후 검사만 하지 마라

- **알게 된 것**: BD ≤ 1 을 적합 제약으로 넣는 비용이 단독 **+2.6**, 앙상블 **+0.4 ㎥/d**
  (p=0.15 / 0.06) 로 측정 한계 안이다. 그 대가로 음폐수 BD 1.14 → **1.000** 이 되어
  모든 계수가 물리적으로 허용 가능해진다.
- **어떻게**: θ_s·G(k_s)/VSfrac_s ≤ B_th,s 는 **계수 하나에 대한 상한**이라 박스 제약이고,
  비음수 최소자승이 그대로 처리한다(SLSQP 조차 필요 없다).
- **달라지는 것**: 밀려난 몫은 절편으로 정직하게 이동한다(34.2% → 37.6%).
  **나빠진 게 아니라 제자리를 찾은 것**이다.

### B5. 단독 최하위 모델이 앙상블에 필수일 수 있다

- **알게 된 것**: M3(VS 물질수지)는 단독 CV-RMSE **967.8 로 최하위**인데,
  앙상블에서 빼면 **유의하게 악화**된다(+38.5, **p=0.0077**).
- **달라지는 것**: 앙상블 멤버는 **단독 성능이 아니라 잔차 독립성**으로 고른다.
  반대로 M1F·M2 는 스태킹이 가중 0 으로 **스스로 배제**했다 — 억지로 넣지 않으면 된다.

### B6. 복잡도를 늘리는 개선은 대개 실패한다

- **2풀 분리**: 튜닝된 단일 풀보다 **유의하게 나빴다**(771.3 vs 749.7, p=0.024).
- **k 튜닝**: 폴드 안에서 고르면 이득이 사라진다(p=0.76).
- **경험식 앙상블 편입**: Δ−4.2, p=0.71, 스태킹 가중 0.030 → 미채택.
- **달라지는 것**: 채택된 두 개(구동 변수 교체·물리 제약)는 **복잡도를 줄이거나 유지**한다.
  "규칙 12(개선 0.01 미만이면 미채택)"는 복잡도 증가를 막는 규칙이므로,
  복잡도가 줄어드는 변경에는 적용하지 않는 것이 맞다.

## C. 검증·평가에 대해 알게 된 것

### C1. 원계열 R² 와 차분계열 R² 는 정반대를 말한다 ⭐ 반드시 병기

- **알게 된 것**: 채택 앙상블의 **원계열 R² = 0.674**, 같은 예측의
  **차분계열 R² = −0.157**. 「내일은 오늘과 같다」는 무변화 모델에 진다.
- **달라지는 것**: 이 모델은 **"주어진 부하에서 반응조가 어느 수준에 있어야 하는가"**를
  맞히고 **"내일의 일변동"**은 맞히지 못한다. 주 단위 계획에 유효, 일 단위 미세 조정에 부적합.
  **원계열 R² 만 제시하면 거짓말에 가깝다.**

### C2. "persistence R²" 는 지평 없이 인용하면 무의미하다

- **알게 된 것**: 같은 계열에서 persistence R² 가 **h=1 전 구간 0.831**
  (2022~23 검증창만 보면 **0.932**), **폴드 원점 기준 90일 블록에서 −0.767**. 전부 참이다.
- **달라지는 것**: 기준선을 인용할 때 **반드시 지평을 붙인다.**
  선행 문서들의 "persistence R²=0.93" 과 우리 표의 "−0.77" 은 모순이 아니라 다른 문제다.

### C3. 선택 편향의 크기를 실제로 재봤다 — 27 ㎥/d

- **알게 된 것**: k 를 **전 폴드 성적으로** 고르면 CV-RMSE 749.7,
  **폴드 학습셋 안에서** 고르면 777.3. 차이 **27 ㎥/d 가 곧 편향의 크기**다.
- **덧붙여**: 폴드별 선택된 k 가 **0.05~0.45 로 흩어진다** — 명세서의 k 95% CI [0.15, 1.50] 과
  같은 이야기다. 안정 식별되지 않는 값을 튜닝해봐야 의미가 없다.
- **달라지는 것**: 이 프로젝트에서 "튜닝으로 좋아졌다"는 보고를 받으면 **27 을 기준으로 의심**한다.

### C4. 평균은 지평 구조를 숨긴다

- **알게 된 것**: 관성 보정의 전체 평균 이득은 Δ−30.2 뿐인데, 지평별로 보면
  h=1–3 에서 **+46%**, h≥15 에서 **0%** 다.
- **어떻게**: 우리 폴드 구성상 h=31~90 이 표본의 **68%** 를 차지한다.
- **달라지는 것**: **지평별 층화 보고를 기본으로 한다.** 운영 지평이 주 단위라면
  평균값은 그 모델의 실제 가치를 크게 과소평가한다.

### C5. 문헌 절대임계를 그대로 경보로 쓰면 경보가 죽는다

- **알게 된 것**: 문헌 임계를 그대로 적용한 발화율 — 소화조 pH **98.4%**,
  OLR 86.2%, FAN 75.1%.
- **달라지는 것**: 경보는 **시설 자체 90일 기준선 대비 상대편차**로 낸다
  (주의 ≥15%, 위험 ≥25% → 위험 71일 / 주의 428일). 문헌 임계는 경보가 아니라
  **"설계·문헌 대비 이 시설이 어디에 있는지"를 보여주는 진단**으로 병기한다.
  이 시설은 pH 7.95·OLR 1.14 로 6년간 안정 운전한 **순치된 계**이고,
  일반 기준 밖에 있는 것이 곧 이상은 아니다.

### C6. 보간 위험은 가정하지 말고 가림 실험으로 재라

- **알게 된 것**: CH₄% 보간 오차 MAE **0.46~0.63 %p**(간격 1~3일)
  → 메탄 **±48~65 ㎥/d**, 모델 RMSE 의 **6~9%**.
- **어떻게**: 관측된 값을 일부러 가리고 복원해 각 간격당 300회 측정.
- **달라지는 것**: "보간 금지"를 교조로 두지 않고 **비용을 알고 결정**할 수 있다.
  결론은 여전히 "타깃은 보간 안 함, 재구성은 보고용만" 이지만 **근거가 생겼다.**

## D. 선행 문서·외부 모델을 다루며 알게 된 것

### D1. 문서는 재현해보기 전에는 믿지 않는다 — 양방향으로

- **재현된 것**: 명세서 §9 코드(test R² 0.772/0.776), W1(0.831 / −0.000),
  Layer 3 일별(r=+0.056, p=0.399, n=229), 경험식 가중치표(소수 셋째 자리까지),
  검토서 전 수치, 참조문서 §7 연도별 표 전체.
- **재현 안 된 것**: 명세서의 연 단위 **r=−0.999 (n=4)** — 반입톤당/투입톤당 어느 정의로도
  나오지 않는다(최대 −0.847). 인용하면 안 된다.
- **달라지는 것**: 재현율이 높다고 전부 믿지 말고, 재현 안 되는 항목은 **그 하나만** 격리한다.
  (이 경우 결론에는 영향 없음 — 문서 자신이 n=4 라 기각하는 대목이었다)

### D2. 예측 성능과 파라미터의 물리 타당성은 별개다 ⚠️

- **알게 된 것**: 현장 경험식은 예측 성능이 우리보다 **유의하게 나쁜데**(Forecast 1,407.9
  vs 836.8, p=0.0004), **수율의 물리 타당성은 더 낫다** — 음폐수 BD **0.90**(우리 1.07 ❌),
  가축분뇨 BD 0.39(문헌 0.45 에 근접).
- **덧붙여**: 단위를 맞추면(정상이득 G 반영) 두 모델의 유효 수율이 **5% 안에서 수렴**한다
  (음식물류 25.5 vs 24.2 ㎥/t). 전혀 다른 경로로 얻은 값이 만나는 것은 강한 신호다.
- **달라지는 것**: 외부 모델과의 대조는 **성능 경쟁이 아니라 수렴 타당성 검사**로 쓴다.
  우리가 이긴 항목만 보면 정작 중요한 결함을 놓친다.

### D3. 세척항이 없는 동역학 모델은 물리 상한을 넘을 수 있다

- **알게 된 것**: 경험식 k_m=0.010 → 반감기 **69.3일**. 그런데 CSTR 세척 때문에
  λ ≥ 1/SRT 이므로 SRT 40.6일에서도 최장 반감기는 **28.1일**이다.
- **달라지는 것**: 소화조 동역학 모델을 검토할 때 **세척항 유무를 먼저 확인**한다.
  없으면 추정된 k 가 물리적으로 불가능한 영역에 들어갈 수 있다.

### D4. 자기회귀 항을 쓰는 모델은 Nowcast/Forecast 를 반드시 구분해 평가한다

- **알게 된 것**: 같은 경험식이 **Nowcast 946.0 / Forecast 1,407.9** — 모드만 바꿔도 462 벌어진다.
  계수를 재적합하면 899.2 로 회복되므로, 열위의 큰 몫은 구조가 아니라 **파라미터 편향
  (−629 ㎥/d)** 이다.
- **달라지는 것**: 구조의 문제와 파라미터의 문제를 분리해서 평가한다.
  그리고 **원래 용도(Nowcast)로 만들어진 식을 Forecast 기준으로 깎아내리지 않는다.**

| # | 버그 | 어떻게 드러났나 | 교훈 |
|---|---|---|---|
| 1 | `OLR × V` 로 유입 VS 산출 | V 민감도 표에서 V=4000 일 때 함축수율 2.94 로 튐 | master 의 `OLR` 은 **이미 V=8,000 으로 나눈 파생열**(OLR×8000 ≡ VS_load×1000, 중앙값 비 1.000). 파생열을 원자료처럼 쓰지 말 것 |
| 2 | SLSQP 제약이 안 걸림 | 제약 유무 결과가 완전히 동일 | 잔차제곱합 스케일이 ~1e10 이라 기본 수렴 판정이 먼저 만족됐다. **목적함수를 정규화**하고 제약 충족을 사후 검증할 것 |
| 3 | BD 판정이 계수 0 에서 "통과" 표시 | 표에서 BD=0 인데 초록불 | NNLS 하한 계수가 정확히 0 이 아니라 **1e-17** 이었다. 경계값은 "판정 불가"로 표시할 것 |
| 4 | 잔차 진단에서 빈 슬라이스 경고 | 2018년 RMSE 계산 시 RuntimeWarning | 초기 학습창에는 **OOF 예측이 없다**. "값 없음"과 "0"을 구분해 표기할 것 |
| 5 | 관성 보정이 h→0 에서 persistence 로 수렴 안 함 | h=1–3 에서 persistence 에 짐 | 잔차 평균 창(window)을 7 로 고정했기 때문. **window 도 격자에 넣자** 특수해(persistence+Δfeed)에 닿았다 |
