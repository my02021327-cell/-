## 3. 문서에 없어 확정한 재현 규약

문서만으로는 재현이 갈리는 지점이 두 곳 있었다. 아래를 **정본 규약**으로 고정하고
검증 스크립트에 박아두었다.

### 3.1 `Y_COD` 의 소화조 COD 는 A·B 평균이다

```python
dig_cod = df[["dig_CODcr_A_mgL", "dig_CODcr_B_mgL"]].mean(axis=1)   # ← A 단독 아님
removed = feed_AB_tpd * (acid_CODcr_mgL - dig_cod) / 1000           # kg COD/d
Y_COD   = CH4_m3d / removed
```

A 단독으로 계산하면 n=1,065·열역학 위반 15.1%가 되어 검토서의 **n=1,072·14.2%** 와
어긋난다. A·B 평균일 때 두 값이 정확히 재현된다.

### 3.2 연도별 집계·상관은 열역학 필터를 적용한 뒤에 낸다

`0 < Y_COD ≤ 0.35`(검토서 B3) 필터를 **먼저** 적용해야 검토서 B2 표가 재현된다.

| | 필터 전 | 필터 후 (검토서와 일치) |
|---|---|---|
| 2018년 Y_COD 중앙값 | 0.423 | **0.281** |
| 2021년 Y_COD 중앙값 | 0.249 | **0.250** |
| Y_COD vs FAN ρ | −0.412 (n=216) | **−0.410 (n=170)** |

필터 없이 집계하면 2018년이 0.423으로 튀어 "FAN 정점 ↔ 수율 최저" 대응이 흐려진다.
검토서 B3의 QC 필터는 선택 사항이 아니라 **B1·B2 수치의 전제**다.

## 4. 검증 중 새로 확인된 사실

문서에 없는 내용으로, 후속 작업에 영향이 있다.

### 4.1 열역학 위반이 연도별로 극단적으로 편중돼 있다 (신규)

검토서 B3은 위반율을 전체 14.2%로만 보고했으나, 연도별로 보면 성격이 다르다.

| 연도 | 유효 n | 열역학 위반율 |
|:---:|:---:|:---:|
| 2018 | 50 | **72.0%** |
| 2019 | 223 | 10.8% |
| 2020 | 215 | 10.2% |
| 2021 | 214 | **0.9%** |
| 2022 | 220 | 12.3% |
| 2023 | 150 | **27.3%** |

- **2018년은 Y_COD 계산 자체가 성립하지 않는다.** 유효 관측이 50건뿐인데 그중 72%가
  물리적으로 불가능하다. 정규화 KPI를 Y_COD로 확정한 이상(검토서 E), **2018년은 KPI
  기준선 산출에서 제외**해야 한다. 이는 기존 `flag_regime_2018`(가스 고분산)과는 별개의,
  COD 계측 신뢰성 문제다.
- 2023년 위반율 27.3%도 평년의 2배 이상이다. 2023 파일이 관리본(미완결)이라는 DQ-01과
  같은 뿌리일 가능성이 있으나 원인은 미확인이다.
- 2021년은 0.9%로 가장 깨끗하다. 공교롭게도 FAN 정점·Y_COD 최저 연도이므로, 검토서 B2의
  핵심 대응이 데이터 품질이 가장 좋은 해에서 나왔다는 점은 그 주장을 강화한다.

### 4.2 `FAN_A/B_mgL` 열의 온도 입력 규약

문서의 `calc_FAN` 예시는 `T=38.0` 고정 대입처럼 읽히지만, CSV의 FAN 열은
**센서결함이 아닌 날은 실측 온도, 결함 구간만 38.0** 으로 산출돼 있다(재현 오차 5e−07).
항상 38.0을 대입하면 최대 141 mg/L까지 어긋나므로 FAN을 재계산할 때 이 규약을 따라야 한다.

```python
T = dig_T_A_C.where(flag_TA_sensor_fault == 0).fillna(38.0)
```

### 4.3 DQ 플래그는 이미 값에 반영되어 있다

`flag_TA_sensor_fault`(398일)·`flag_TB_sensor_fault`(94일)·`flag_ALKB_corrupted`(260일)
구간의 해당 측정 열은 **전부 NaN으로 마스킹된 상태**다. 따라서 설계문서 §3 전처리
파이프라인의 ① 단계(플래그 적용)는 이 CSV에서는 **무연산(no-op)** 이다. 플래그 열은
"이 결측이 왜 비어 있는지"를 알려주는 사유 코드로 쓰고, 마스킹을 다시 적용하려 하거나
해당 구간에서 원값을 찾지 말 것.

### 4.4 참조문서 §7 온도 행과 CSV 값이 다른 것은 정상이다

| | 참조문서 §7 | CSV 재계산 |
|---|---|---|
| T_A 2022 | 36.58 | 38.44 |
| T_A 2023 | 26.44 | (전부 NaN) |
| T_B 2023 | 36.66 | 36.99 |

참조문서 표는 **마스킹 전 원자료** 기준이고 CSV는 마스킹 후다. 표류·고착된 저온값이
제거되면서 평균이 올라간 것이므로 방향이 일관되며, 결함이 아니다. 온도의 "연도별 하락"은
실제 냉각이 아니라 센서 표류라는 DQ-02 판정과도 부합한다.

### 7.1 연 단위 r=−0.999 는 재현되지 않는다

"반입톤당 메탄"의 정의를 바꿔가며 시도했으나 −0.999에 근접하는 조합이 없다.

| 정의 | n=5 (2018–22) | n=4 (2018–21) | n=4 (2019–22) |
|---|:---:|:---:|:---:|
| CH₄ / 반입량(intake_total) | r=−0.770 | −0.847 | −0.625 |
| CH₄ / 투입량(feed_AB) | r=−0.230 | −0.222 | +0.313 |

명세서가 병기한 실측값("반입톤당메탄 29.8→25.8")도 CSV 재계산값(35.4→30.5, 반입 기준)과 다르다.
다만 **이 수치는 명세서 자신이 "n=4라 인과 증거가 될 수 없다"며 기각하는 맥락**에 있고, Layer 3
철회 판정의 근거는 일별 분석(정확히 재현됨)이다. 따라서 **결론은 영향받지 않으나, r=−0.999 를
인용해서는 안 된다.** 만성 저해 가설을 연 단위로 뒷받침하려면 −0.77~−0.85 범위로 기술해야 하며,
그마저 n=5의 관측이다.

### 7.2 Layer 1 잔차 σ 차이

명세서는 잔차 σ=1,281 ㎥/d, 재계산은 **1,538 ㎥/d**(k=0.35 단일특징 OLS, 전기간)이다. 명세서의
Layer 2 표가 어느 Layer 1 모델(채택 가수분해 모델인지 RF인지)의 잔차인지 명시하지 않아 생긴 차이로
보인다. 상관계수의 부호·순위·유의성은 모두 일치하므로 결론(내부 이화학은 진단 계층)은 유지된다.
**Layer 2를 실제 구현할 때는 어느 Layer 1 잔차를 쓰는지 명시할 것.**

## 8. 선행 저장 문서와의 충돌 (모델링 착수 전 해소 필요)

### 12.1 기준선 재현 — 선행 보고와 방향·크기 모두 일치

| 사양 | 선행 보고 | 재계산 |
|---|---:|---:|
| 기존 전단 + 무절편 | 946.6 | 922.7 |
| 기존 전단 + 절편 | 884.1 | 855.6 |
| 문헌 전단 + 무절편 | 905.8 | 884.7 |
| **문헌 전단 + 절편** | **861.5** | **836.8** |

전부 2~3% 낮게 나오지만 **순서와 간격이 동일**하다. PROMPT §5.4 의 핵심 주장도 재현된다:
문헌 기질별 전단 커널이 기존 공통 커널을 유의하게 이기고(ΔRMSE −38.0, p=0.0035),
전단 지연을 제거하면 크게 악화된다(836.8 → 942.0, p<0.001).

### 12.2 SRT 비식별성이 독립적으로 재확인됐다

V 를 4,000 → 8,000 ㎥ 로 **두 배** 바꿔도 CV-RMSE 가 소수점 이하로만 움직인다
(ΔRMSE 0.00~0.03, **p = 0.89 ~ 0.99**). PROMPT §5.2 의 "여섯 경로 전부 실패"에
일곱 번째 음성 결과를 더한다. SRT 는 외생 입력으로 두는 것이 맞다.

### 12.3 새로 확인된 사실 — 물질수지 이탈은 V 로 해소되지 않는다

PROMPT §4 는 이탈 원인 후보로 "V 또는 소화액 VS% 오류"를 든다. 그런데 **유입·유출·소비 VS
는 모두 V 와 무관하다**(유입 = 부하 원자료, 유출 = Q_out × VS%). V 는 조내 VS 와 SRT 에만
들어간다. 따라서 **용적을 바꿔서는 이 이탈을 설명할 수 없고**, 남는 후보는 유입 VS 과소
계량과 CH₄ 계량 과대 둘이다. 계량 감사의 우선순위가 좁혀진다.

> 부수 확인: master 의 `OLR_kgVS_m3d` 는 이미 V=8,000㎥ 로 나눈 파생열이다
> (OLR×8000 ≡ VS_load_tpd×1000, 중앙값 비 1.000). `OLR × V` 로 유입 VS 를 만들면
> V≠8000 에서 부하가 잘못 스케일된다 — 초기 구현에서 실제로 이 오류가 났고 수정했다.

### 12.4 앙상블이 기준선을 유의하게 이긴다

| 결합 | CV-RMSE | Δ vs 기준선 | p |
|---|---:|---:|---:|
| **단순평균 (채택)** | **724.2** | **−112.7** | **0.0064** |
| NNLS 스태킹 | 728.3 | −108.6 | 0.0103 |
| 성능가중평균 | 746.4 | −90.4 | 0.0038 |

2023 홀드아웃(모델 선택에 미사용, 1회 보고): RMSE 536, MAPE 6.7%, R² 0.765.

ablation 에서 **M3(VS 물질수지) 제거가 앙상블을 유의하게 악화**시킨다(+38.5, p=0.0077).
M3 는 단독 CV-RMSE 967.8 로 5개 계열 중 최하위인데도 그렇다 — 귀납 편향이 달라서다.
반대로 M1 은 스태킹 가중치 0 으로 자동 배제됐다(제거해도 p=0.43).

### 12.5 내부 이화학은 하나도 채택되지 않았다

§6 포함/제외 대응 t검정에서 T3 변수 11종 **전부 p ≥ 0.05** 로 예측 모델에서 배제됐다
(최소 p=0.07, `VFA_ALK_A`). 폐기하지 않고 건강상태 프로그램으로 재배치했다. 이는 저장된
명세서 W2("소화조 내부 이화학으로 가스량 예측 불가")를 독립 검증으로 재확인한 것이다.

### 12.6 T1 이탈 규칙이 발화했다 — 규정대로 전환했다

- 음폐수 BD 적합값 **1.126 > 1** → 화학양론 강제 해제(본 구현은 처음부터 자유 계수)
- 절편 **2,924 ㎥/d = 실측의 42.9%** > 15% → "T1 단독 예측 중단, T2·T3 결합으로 이관"

NNLS 가 가축분뇨·음식물 계수를 0 으로 밀고 절편이 42.9% 를 가져간다. PROMPT §5.3 의
"미설명 메탄 32%"를 **더 크게** 재확인한 것이다. **이 모델의 계수를 생분해도·수율로
해석해서는 안 된다** — 물리 검사 미통과로 명시했다.

### 12.7 건강상태 프로그램 — 문헌 임계를 그대로 쓰지 않았다

PROMPT §6 표의 문헌 임계를 그대로 적용하면 경보가 상시 발화한다:

| 지표 | 문헌 임계 발화율 | 시설 기준선 대비 발화율 |
|---|---:|---:|
| 소화조 pH (6.8~7.6 이탈) | **위험 98.4%** | 0.0% |
| OLR (1.5~4.0 밖) | 주의 86.2% | 주의 23.8% |
| FAN (>300) | **위험 75.1%** | 위험 16.7% |

이 시설은 pH 7.95·OLR 1.14 로 6년간 안정 운전한 **순치된 계**이고, 일반 설계 기준 밖에
있는 것이 곧 이상은 아니다. 저장소 문서가 `FAN>300` 에서 이미 지적한 실패와 같은 구조다.
따라서 **경보는 시설 자체 90일 기준선 대비 상대편차**(주의 ≥15%, 위험 ≥25%)로 내고,
문헌 임계는 "설계 대비 이 시설의 위치"를 보여주는 진단으로만 병기했다.
결과: 위험 71일 / 주의 428일 / 정상 745일 (측정일 기준).

### 12.8 PROMPT 와 저장된 명세서의 충돌 — M2

PROMPT §7 은 M2(ADL, 자기회귀 분포시차)를 명시 요구하지만, 저장된 명세서 W1 은 `y_lag1`
사용을 금지한다(반응조 관성이 만드는 허위 R²). **지시대로 구현하되**, 90일 앞 예측에서
`y(t−1)` 을 관측값으로 넣는 것은 곧 누출이므로 **재귀 시뮬레이션**으로 굴렸다. 결과
M2 단독 868.4(기준선 대비 p=0.53), 앙상블 가중치 0.032 로 사실상 기여가 없다 —
W1 의 경고와 모순되지 않는다. 함축 HRT 는 φ=0.870 → 7.2일로, 설계 HRT 40.5일과 크게 다르다.
