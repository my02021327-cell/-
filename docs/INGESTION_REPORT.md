## 3. 문서에 없어 확정한 재현 규약

문서만으로는 재현이 갈리는 지점이 두 곳 있었다. 아래를 **정본 규약**으로 고정하고
검증 스크립트에 박아두었다.

### 3.1 `Y_COD` 의 소화조 COD 는 A·B 평균이다

```python
dig_cod = df[["dig_CODcr_A_mgL", "dig_CODcr_B_mgL"]].mean(axis=1)   # ← A 단독 아님
removed = feed_AB_tpd * (acid_CODcr_mgL - dig_cod) / 1000           # kg COD/d
Y_COD   = CH4_m3d / removed
```

A 단독으로 계산하면 n=1,065·열역학 위반 15.1%가 되어 검토서의 **n=1,072·14.2%** 와
어긋난다. A·B 평균일 때 두 값이 정확히 재현된다.

### 3.2 연도별 집계·상관은 열역학 필터를 적용한 뒤에 낸다

`0 < Y_COD ≤ 0.35`(검토서 B3) 필터를 **먼저** 적용해야 검토서 B2 표가 재현된다.

| | 필터 전 | 필터 후 (검토서와 일치) |
|---|---|---|
| 2018년 Y_COD 중앙값 | 0.423 | **0.281** |
| 2021년 Y_COD 중앙값 | 0.249 | **0.250** |
| Y_COD vs FAN ρ | −0.412 (n=216) | **−0.410 (n=170)** |

필터 없이 집계하면 2018년이 0.423으로 튀어 "FAN 정점 ↔ 수율 최저" 대응이 흐려진다.
검토서 B3의 QC 필터는 선택 사항이 아니라 **B1·B2 수치의 전제**다.

## 4. 검증 중 새로 확인된 사실

문서에 없는 내용으로, 후속 작업에 영향이 있다.

### 4.1 열역학 위반이 연도별로 극단적으로 편중돼 있다 (신규)

검토서 B3은 위반율을 전체 14.2%로만 보고했으나, 연도별로 보면 성격이 다르다.

| 연도 | 유효 n | 열역학 위반율 |
|:---:|:---:|:---:|
| 2018 | 50 | **72.0%** |
| 2019 | 223 | 10.8% |
| 2020 | 215 | 10.2% |
| 2021 | 214 | **0.9%** |
| 2022 | 220 | 12.3% |
| 2023 | 150 | **27.3%** |

- **2018년은 Y_COD 계산 자체가 성립하지 않는다.** 유효 관측이 50건뿐인데 그중 72%가
  물리적으로 불가능하다. 정규화 KPI를 Y_COD로 확정한 이상(검토서 E), **2018년은 KPI
  기준선 산출에서 제외**해야 한다. 이는 기존 `flag_regime_2018`(가스 고분산)과는 별개의,
  COD 계측 신뢰성 문제다.
- 2023년 위반율 27.3%도 평년의 2배 이상이다. 2023 파일이 관리본(미완결)이라는 DQ-01과
  같은 뿌리일 가능성이 있으나 원인은 미확인이다.
- 2021년은 0.9%로 가장 깨끗하다. 공교롭게도 FAN 정점·Y_COD 최저 연도이므로, 검토서 B2의
  핵심 대응이 데이터 품질이 가장 좋은 해에서 나왔다는 점은 그 주장을 강화한다.

### 4.2 `FAN_A/B_mgL` 열의 온도 입력 규약

문서의 `calc_FAN` 예시는 `T=38.0` 고정 대입처럼 읽히지만, CSV의 FAN 열은
**센서결함이 아닌 날은 실측 온도, 결함 구간만 38.0** 으로 산출돼 있다(재현 오차 5e−07).
항상 38.0을 대입하면 최대 141 mg/L까지 어긋나므로 FAN을 재계산할 때 이 규약을 따라야 한다.

```python
T = dig_T_A_C.where(flag_TA_sensor_fault == 0).fillna(38.0)
```

### 4.3 DQ 플래그는 이미 값에 반영되어 있다

`flag_TA_sensor_fault`(398일)·`flag_TB_sensor_fault`(94일)·`flag_ALKB_corrupted`(260일)
구간의 해당 측정 열은 **전부 NaN으로 마스킹된 상태**다. 따라서 설계문서 §3 전처리
파이프라인의 ① 단계(플래그 적용)는 이 CSV에서는 **무연산(no-op)** 이다. 플래그 열은
"이 결측이 왜 비어 있는지"를 알려주는 사유 코드로 쓰고, 마스킹을 다시 적용하려 하거나
해당 구간에서 원값을 찾지 말 것.

### 4.4 참조문서 §7 온도 행과 CSV 값이 다른 것은 정상이다

| | 참조문서 §7 | CSV 재계산 |
|---|---|---|
| T_A 2022 | 36.58 | 38.44 |
| T_A 2023 | 26.44 | (전부 NaN) |
| T_B 2023 | 36.66 | 36.99 |

참조문서 표는 **마스킹 전 원자료** 기준이고 CSV는 마스킹 후다. 표류·고착된 저온값이
제거되면서 평균이 올라간 것이므로 방향이 일관되며, 결함이 아니다. 온도의 "연도별 하락"은
실제 냉각이 아니라 센서 표류라는 DQ-02 판정과도 부합한다.

### 7.1 연 단위 r=−0.999 는 재현되지 않는다

"반입톤당 메탄"의 정의를 바꿔가며 시도했으나 −0.999에 근접하는 조합이 없다.

| 정의 | n=5 (2018–22) | n=4 (2018–21) | n=4 (2019–22) |
|---|:---:|:---:|:---:|
| CH₄ / 반입량(intake_total) | r=−0.770 | −0.847 | −0.625 |
| CH₄ / 투입량(feed_AB) | r=−0.230 | −0.222 | +0.313 |

명세서가 병기한 실측값("반입톤당메탄 29.8→25.8")도 CSV 재계산값(35.4→30.5, 반입 기준)과 다르다.
다만 **이 수치는 명세서 자신이 "n=4라 인과 증거가 될 수 없다"며 기각하는 맥락**에 있고, Layer 3
철회 판정의 근거는 일별 분석(정확히 재현됨)이다. 따라서 **결론은 영향받지 않으나, r=−0.999 를
인용해서는 안 된다.** 만성 저해 가설을 연 단위로 뒷받침하려면 −0.77~−0.85 범위로 기술해야 하며,
그마저 n=5의 관측이다.

### 7.2 Layer 1 잔차 σ 차이

명세서는 잔차 σ=1,281 ㎥/d, 재계산은 **1,538 ㎥/d**(k=0.35 단일특징 OLS, 전기간)이다. 명세서의
Layer 2 표가 어느 Layer 1 모델(채택 가수분해 모델인지 RF인지)의 잔차인지 명시하지 않아 생긴 차이로
보인다. 상관계수의 부호·순위·유의성은 모두 일치하므로 결론(내부 이화학은 진단 계층)은 유지된다.
**Layer 2를 실제 구현할 때는 어느 Layer 1 잔차를 쓰는지 명시할 것.**

## 8. 선행 저장 문서와의 충돌 (모델링 착수 전 해소 필요)

명세서는 1차 편입 문서들보다 나중 단계(모델 비교 완료)의 산출물이며, 아래를 명시적으로 철회·정정한다.
**이후 모델링에서는 명세서를 우선하되, 각 항목의 근거를 재확인한 뒤 적용한다.**

| 쟁점 | 선행 문서 | 명세서 (최신) | 상태 |
|---|---|---|---|
| `y_lag1` 피처 | 설계 §4.3 **T1 필수** | **사용 금지** (W1: 반응조 관성이 만든 허위 R²) | 🔴 정면 충돌 |
| 예측 지평 | 검토서 A2: 주 타깃 **h=7·14일** | 당일 예측(가수분해 커널), 지평 논의 없음 | 🔴 미해소 |
| 분할 | 학습 2018~21 / **검증 2022~23** | 학습 2018~21 / **valid 2022 / test 2023** (3분할) | 🟠 명세서 채택 |
| FAN 경보 | 검토서 A1: 폐기 → Y_COD 상대편차 | Layer 3 **검증 실패·철회** (일별 p=0.399) | ✅ 방향 일치 |
| VFA/Alk | 설계 §4.3 **T2 피처** | 잔차상관 r=0.042 → **관리지표에서 제외** | 🟠 명세서 채택 |

> 둘 다 성립할 수 있다(전자는 예측 용도, 후자는 응답 동역학). **모델링 착수 시 어느 용도인지 먼저 확정할 것.**

## 9. 명세서가 새로 제기한 미해결 항목

명세서 §7의 O1~O6은 대부분 **시설 측 정보나 외부 데이터가 있어야 풀린다** (단상 대조군 확보,
2022년 정비 이력, VS 분석 SOP 변경 이력). 데이터만으로 진행 가능한 것은 O6(계수 시변성 대응)과
O2(선행연구 검색)뿐이다. 모델링 착수 시 이 구분을 먼저 확인할 것.
