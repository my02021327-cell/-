## 0. 핵심 결과 — 생물반응은 검증되었으나 예측에는 기여하지 않는다

생물반응 6종을 모델에 편입해 검증했다. 결과가 명확하게 갈렸다.

| 반응 | 검증 결과 | 예측 기여 |
|------|-----------|:---:|
| 화학량론 (COD→CH₄ 상한) | ✅ **PASS** — Y_COD = 이론치의 82.6% | ❌ |
| 1차 가수분해 동역학 | ❌ **REJECT** — 전환율이 HRT에 무반응 | — |
| 탄산 평형 (pH↔알칼리도↔pCO₂) | 🟡 **PARTIAL** — 수준 정합(RMSE 0.165), 변동 미설명 | ❌ |
| 탄산 잔차의 암모니아 프록시 | ❌ **REJECT** — pH 통제 후 무관 (순환) | — |
| 알칼리도의 암모니아 프록시 | ✅ **PASS(추세 한정)** — TAN과 ρ=0.615 | ❌ (관제용) |
| 전환효율 η / 상분리 / OLR | 검증됨 | ❌ |

**예측 성능 (rolling-origin 3폴드, skill = 1 − MSE_model/MSE_persistence):**

| 지평 | 평균회귀만 (생물학 없음) | + 생물반응 | 생물반응만 |
|:---:|:---:|:---:|:---:|
| h=1일 | **+0.001** | −0.005 | −0.004 |
| h=3일 | **+0.015** | −0.055 | −0.062 |
| h=7일 | **+0.083** | −0.011 | −0.038 |
| h=14일 | **+0.154** | −0.037 | −0.012 |
| h=30일 | **+0.290** | +0.112 | +0.050 |

> **모든 지평에서 생물반응을 추가하면 성능이 나빠진다.** 최선은 가스 이력만 쓰는
> 평균회귀 모델이며, 최소 폴드에서도 양수를 유지한다(h=7 +0.042, h=14 +0.060, h=30 +0.247).

### 왜 그런가 — 생물학은 수준을, 부하는 변동을 결정한다

일별 상대변화(중위)를 비교하면 원인이 드러난다.

| 변수 | CV | 일별 상대변화 |
|------|:---:|:---:|
| 소화조 pH | 1.7% | **0.25%** |
| 알칼리도 | 6.2% | **0.89%** |
| 산발효조 pH | 14.6% | 1.72% |
| VFA/알칼리도 | 18.6% | 3.41% |
| COD 부하 | 23.9% | 7.12% |
| 전환효율 η | 13.5% | 7.17% |
| **바이오가스 (예측 대상)** | 23.7% | **2.70%** |

소화조 내부 상태는 일별로 **거의 정지**(pH 0.25%, 알칼리도 0.89%)한다. HRT 40.5일의
완전혼합조에서 하루에 내용물의 2.5%만 교체되므로 당연한 결과다. 즉 생물학 상태는
**수준(level)과 연 단위 추세**를 결정하고, 일별 변동은 부하와 계측 노이즈가 지배한다.

> **설계 함의**: 생물반응은 예측 피처가 아니라 **상태 진단 지표**로 배치해야 한다.
> 이는 "암모니아는 관제에서만 고려" 지시와 같은 결론에 도달한다 — 데이터가 그 지시를
> 암모니아뿐 아니라 **느린 생물학 전체**로 확장할 것을 요구한다.

## 1. 생물반응별 검증 상세

### 1.1 화학량론 — PASS (모델의 물리 천장으로 채택)

```
COD 부하   = feed_AB × acid_CODcr           = 28,747 kg COD/d (중위)
COD 제거   = feed_AB × (acid − dig) COD     = 23,237 kg/d (제거율 81.1%)
Y_COD      = CH4_m3d / COD_removed          = 0.289 m³/kg   (n=920)
이론 상한  = 0.35 m³ CH₄/kg COD             → 관측은 82.6%
```

문헌상 제거 COD의 10~17%가 균체 합성에 소비되므로 기대 창은 83~90%. **82.6%는 이 창의
하단에 접한다** — 물질수지가 닫힌다는 뜻이다. 모델에서 이를 상한 제약으로 고정한다:

```python
CH4_stoich_cap = 0.35 × COD_removed          # 넘을 수 없는 생물학적 천장
eta = CH4_obs / CH4_stoich_cap               # 전환효율 = 저해 상태의 직접 측도
```

`eta > 1` 또는 `≤ 0`은 물리적으로 불가능하므로 **QC 필터**로도 쓴다(관측의 14.2%가 이에
해당 — 참조문서 DQ 목록에 없던 검증 규칙).

### 1.2 1차 가수분해 동역학 — REJECT

CSTR 정상상태 1차 반응이면 `X/(1−X) = k·HRT`가 성립해야 한다. 검정 결과:

```
HRT 범위        : 30.8 ~ 55.6 일 (5~95%)
전환율 X        : 중위 0.811, CV 5.3%          ← 거의 상수
HRT vs X        : rho = −0.105                 ← 무관
X/(1−X) ~ HRT   : 기울기 −0.0131 (음수), 절편 4.91
```

**HRT가 31→56일로 1.8배 변해도 전환율이 움직이지 않는다.** 1차 동역학이라면 있을 수
없다. 해석: 이 반응기는 **동역학 제한이 아니라 기질 생분해도 제한** 상태다. OLR 1.14
(문헌 권장 1.5~4.0의 하단), HRT 40.5일(통상 20~30일 초과)이라는 기존 진단과 정확히
일치한다.

대안으로 난분해성 분율 모델을 검정했다: `COD_out = 0.111·COD_in + 11,369` (R²=0.335).
절편이 평균 COD_out의 41.6%로 크므로 순수 비례 모델도 아니다 — 유출 COD는 유입 성상보다
**반응기 정상상태(균체·잔류 난분해물)** 가 지배한다.

> **모델 반영**: `k_h`를 파라미터로 쓰지 않는다. 전환율을 상수 `X=0.811`로 고정한다.
> **운전 함의**: HRT나 부하를 조정해도 전환율은 개선되지 않는다. 개선 여지는 기질
> 생분해도(= 혼합비)에 있다.

### 1.3 탄산 평형 — PARTIAL

```
pH_pred = pK1 + log10( [HCO3⁻] / (K_H · pCO₂) )      pK1=6.31, K_H=0.0257 (38℃)
[HCO3⁻] ← 중탄산 알칼리도 = ALK − 0.71 × VFA
pCO₂    ← 가스 CO₂% (미측정일은 100 − CH₄% − 1)
```

| 항목 | 값 |
|------|-----|
| 관측 pH 중위 | 7.970 |
| 예측 pH 중위 | 7.849 |
| 편차 (관측−예측) | **+0.109** |
| RMSE | **0.165** pH 단위 |
| 예측-관측 상관 | r=+0.141 (약함) |

**수준은 정합하지만 일별 변동을 설명하지 못한다.** pH의 CV가 1.7%(≈0.14 단위)로 계측
분해능 수준이므로 예측 가능한 변동 자체가 거의 없다. 체계적 양의 편차(+0.109)는
비탄산 완충(암모늄) 기여와 방향이 일치하며, 연도별로 2018년 0.046 → 2021년 0.180으로
커진다. 다만 아래 1.4에서 보듯 이를 암모니아 지표로 쓸 수는 없다.

> **모델 반영**: 예측 피처가 아니라 **일관성 QC**로 사용한다(RMSE 0.165 기준 3σ 이탈은
> pH·알칼리도·가스조성 중 하나의 계측 오류를 시사).

### 1.4 탄산 잔차를 암모니아 프록시로 — REJECT (순환)

`pH_excess = pH_obs − pH_carbonate`가 암모늄 기여를 담을 것으로 기대했고, FAN과 강한
상관(ρ=+0.648, p=2.2e−28)이 나왔다. **그러나 이는 순환이다.**

| 대조 | vs FAN | vs TAN (암모니아 부하 실체) |
|------|:---:|:---:|
| 탄산 잔차 | +0.648 | **+0.077 (p=0.25, 유의하지 않음)** |
| 생 pH | +0.767 | +0.152 |
| **알칼리도** | +0.466 | **+0.615 (p=1.6e−24)** |

`FAN = TAN/(1+10^(pKa−pH))`이므로 **pH를 포함한 어떤 지표도 FAN과 자동 상관**한다.
판정 기준은 TAN(부하 실체)과의 상관이다. 결정적으로, **pH를 통제한 부분상관에서
잔차와 TAN은 r=−0.035 (p=0.60)** — 독립 정보가 전혀 없다.

> **기각.** 대신 **알칼리도**가 TAN과 ρ=0.615로 가장 강하고, pH를 포함하지 않으므로
> 순환이 아니며, **일별 측정(n=1,257)** 이라 NH₃-N이 2023년 0건인 상황에서 유일하게
> 가용한 프록시다. 단 절대값 추정용이 아니라 국면 분류용이다(§2).

## 2. 소화조 상태 점검 프로그램 — 급성 경보와 만성 상태의 분리

암모니아 저해는 여기서 전담한다. 설계의 핵심은 **급성과 만성을 한 지표로 묶지 않는
것**이다. 발화율의 의미가 서로 다르기 때문이다.

### 2.1 급성 경보 — 발화율이 낮아야 경보로 기능한다

| 규칙 | 정의 | 발화일 | 발화율 |
|------|------|:---:|:---:|
| **A1** 성능저하 | Y_COD가 90일 기준선 대비 −15% | 81 | 3.9% |
| **A2** 급성 산성화 | VFA/알칼리도 3일 이동평균 > 0.30 | 4 | 0.2% |
| **A3** 설명불가 이탈 | 가스 예측 잔차 \|z\|>3, 2일 연속 | 5 | 0.2% |
| **A4** FAN 급등 | FAN이 자체 90일 기준선의 1.2배 초과 | 58 | 2.8% |

종합: **정상 1,940일(93.0%) / 주의 144일(6.9%) / 경보 2일(0.1%)**

### 2.2 만성 상태 — 발화율 = 그 국면의 실제 유병률

`C1 암모니아 부하지수` = 알칼리도의 **2019년(Y_COD 최고 0.310 = 건강 기준기간) 대비
상승률**, 30일 중위 평활.

| 국면 | 부하지수 | 일수 | 비율 |
|------|:---:|:---:|:---:|
| 정상 | < 5% | 623 | 29.9% |
| 경계 | 5~10% | 417 | 20.0% |
| 만성부하 | 10~15% | 635 | 30.4% |
| 고부하 | ≥ 15% | 397 | 19.0% |

연도별로 단조 진행하며 건강기(2018–19)와 부하기(2020–23)를 정확히 분리한다.

| 연도 | FAN 중위 | 알칼리도 | 부하지수 | Y_COD | 급성 발화율 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| 2018 | 317 | 15,763 | 0.5% | 0.28 | 5.5% |
| 2019 | 374 | 15,648 | 0.0% | **0.31 (최고)** | 8.2% |
| 2020 | 347 | 17,173 | 9.8% | 0.30 | 11.7% |
| **2021** | **595 (최고)** | 17,549 | 12.2% | **0.25 (최저)** | 3.6% |
| 2022 | 419 | 18,040 | 14.7% | 0.29 | 4.7% |
| 2023 | (없음) | 18,058 | **15.4%** | 0.30 | 8.8% |

### 2.3 폐기한 규칙과 그 이유

**v2 §5 L1 `FAN > 300 mg/L`을 최상위 경보로 둔 설계는 폐기한다.** 측정 229일 중
**발화율 75.1%** — 3일 중 2~3일 울리는 경보는 경보가 아니다. 원인은 두 겹이었다.

1. **순치 상태 무시.** 이 시설은 TAN 3,832~4,913 mg/L에서 6년간 붕괴 없이 운전된
   순치(acclimated)된 계다. 비순치 문헌 임계(150/300/600)를 그대로 쓸 수 없다.
2. **범주 오류.** 더 근본적으로, **만성 상태를 급성 경보로 표현**하려 한 것이 문제였다.
   → 급성분(A4 상대편차, 2.8%)과 만성분(C1 부하지수, 국면 분류)으로 분리해 해결했다.

또한 **회전창 변화율만 쓰는 설계도 실패**한다(초기 구현에서 확인). 알칼리도가 2020년에
상승한 뒤 고원에 머무르므로, 변화율 지표는 최악 연도(2021)에서 오히려 발화율이
최저(1.4%)가 된다. 만성 축적에는 **고정 기준기간 대비 수준**이 필요하다.

### 2.4 알칼리도를 읽는 방향 — 이 시설 고유의 함정

**알칼리도 상승을 완충능 개선으로 읽으면 안 된다.** NH₄⁺가 CO₂와 결합해 NH₄HCO₃를
형성하며 총알칼리도로 계측되므로(`ALK = 14,089 + 0.640·TAN`), 이 시설에서 알칼리도
상승은 **암모니아 축적 신호**다. 관제 화면과 운전일지 서식에 이 방향을 명시해야 한다.

### 2.5 남은 한계

- 부하지수(알칼리도 기반)는 **TAN 축적**을 포착하지만 **FAN**은 pH에도 의존한다.
  2021년은 FAN이 595로 정점(TAN + pH 동시 상승)이었고 Y_COD가 최저였는데, 부하지수는
  12.2%로 2022~23(14.7~15.4%)보다 낮다. 즉 **부하지수는 FAN의 완전한 대체가 아니다.**
  NH₃-N 측정이 재개되면 A4/C1을 FAN 기반으로 승급해야 한다.
- 2023년은 NH₃-N 0건이므로 A4가 전혀 작동하지 않는다(급성 발화 8.8%는 A1·A3 기여).

## 3. 최종 모델 구조 (v3)

```
【예측】 bio_model.py — 생물학 상태변수 제외 (검증 결과)
  ŷ(t+h) = y(t) + λ_h · Δ̂
    Δ̂     : Ridge/GBM, 입력 = 가스 이력(lag 1·2·3·7·14, 7·30일 평균, 추세) + 요일
    λ_h   : 수축계수. **학습구간 내부의 마지막 해를 검증블록으로 결정** (테스트 누수 금지)
            λ=1(무수축)이면 베이스라인보다 나빠진다 — h=14에서 skill −1.87
    주 지평: h = 7·14일 (운영 의사결정 주기). h=1은 persistence가 R²=0.94로 지배
  필수 병기: 지평별 persistence R²/RMSE/MAE 및 skill score

【진단】 bio_model.verify_biology() — 생물반응 검증 (모델 피처 아님)
  화학량론 상한, 전환율, 탄산 평형을 QC·해석용으로 상시 산출

【관제】 health_check.py — 생물학 전담. 암모니아 저해 명시적 고려
  급성 경보 A1~A4 (발화율 낮음)  +  만성 국면 C1 (유병률)
```

### 검증 프로토콜에서 확인한 함정 3건

1. **레벨 직접 회귀 금지.** `y(t+h)`를 직접 학습하면 트리 모델이 훈련 평균으로 수축해
   모든 지평에서 persistence에 패배한다(h=7 skill −0.90). 반드시 `Δ = y(t+h) − y(t)`를
   학습하고 베이스라인에 가산한다.
2. **λ 탐색에 테스트 구간 사용 금지.** 검증구간에서 λ를 고르면 h=7 skill이 +0.061로
   보이지만 누수다. 학습구간 내부 검증블록에서 정하면 +0.083(평균회귀 단독).
3. **베이스라인 오지정 주의.** h≥7일에서도 **단일일 y(t)가 이동평균보다 우수**하다
   (h=14: y(t) R²=0.326 vs 7일평균 0.308 vs 30일평균 0.130). 평활은 오히려 해롭다.
